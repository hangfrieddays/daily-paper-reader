## 摘要
现代扩散模型生成高质量的图像和视频，但其迭代去噪过程使推理成本高昂。特征缓存通过重用或预测相邻去噪步骤的中间激活来加速采样，利用了逆向轨迹中计算的冗余性。本文中，我们关注缓存调度：选择哪些去噪步骤应完全重新计算。现有调度要么是固定的（如均匀调度），要么是基于每步误差启发式自适应选择；在两种情况下，实际计算成本都是手工调整阈值的副作用，而非用户可指定的量。我们提出ReCache，它颠倒了这一关系：给定目标预算k，它学习最大化生成质量的重新计算调度，将计算转化为可直接控制的输入。ReCache通过策略梯度训练，避开了通过完整扩散推理的反向传播，且不使用标注数据。来自无缓存推理的生成作为匹配目标，并配以生成质量的奖励。ReCache兼容任何缓存机制，包括特征重用和特征预测；对于每种机制，单个训练好的策略可在推理时适应不同的计算预算。ReCache在调度基线上持续取得优势：在FLUX上将FLOPs减少×5.04，与DiCache相比，LPIPS降低31%（从0.456降至0.316）；在Wan 2.1上达到约×2.6加速，与均匀HiCache相比，LPIPS降低65%（从0.480降至0.169），VBench得分提高7%（5.6分，从70.4提高到76.0）。代码可在https://github.com/thecrazymage/ReCache获取。

## Abstract
Modern diffusion models generate high-quality images and videos, but their iterative denoising process makes inference expensive. Feature caching accelerates sampling by reusing or predicting intermediate activations across neighboring denoising steps, exploiting the redundancy of computations along the reverse trajectory. In this work, we focus on the caching schedule: selecting which denoising steps should be fully recomputed. Existing schedules are either fixed (e.g. uniform) or chosen adaptively from per-step error heuristics; in both cases, the actual compute cost is a side-effect of hand-tuned thresholds rather than a quantity the user can specify. We propose ReCache, which inverts this: given a target budget k, it learns the recomputation schedule that maximizes generation quality, turning compute into a directly controllable input. ReCache trains via policy gradients, sidestepping backpropagation through full diffusion inference, and uses no labelled data. Generations from uncached inference serve as matching targets, paired with a reward for generation quality. ReCache is compatible with any caching mechanism, including feature reuse and feature forecasting; for each mechanism, a single trained policy adapts across computational budgets at inference time. ReCache consistently outperforms scheduling baselines: under a $\times5.04$ FLOPs reduction on FLUX, it reduces LPIPS by 31% (from 0.456 to 0.316) compared to DiCache; on Wan 2.1 at a $\sim \times2.6$ speedup, it drops LPIPS by 65% (from 0.480 to 0.169) and boosts the VBench score by 7% (5.6 points, from 70.4 to 76.0) over uniform HiCache. Code is available at https://github.com/thecrazymage/ReCache.

### 论文提出的方法论：核心思想、关键技术细节

**核心思想**：将缓存调度选择建模为预算感知的强化学习（RL）问题，使用策略梯度（REINFORCE）优化一个轻量级MLP策略网络，使其输出每个去噪步骤的重要性logits，并基于Gumbel-Top-k采样得到恰好k个需要完全计算的步骤。训练时无需标注数据，以无缓存推理的输出作为匹配目标，并结合生成质量奖励（HPSv2）最大化生成质量。

**关键技术细节**：

- **策略参数化**：使用Plackett-Luce分布，每个步骤i分配logit θ_i，通过Gumbel-Top-k技巧采样k个子集；logits通过预算条件MLP生成：θ = MLP_ϕ(k)，使单个策略适应不同预算。
- **损失函数**：包含两个目标：1）Fidelity项：采用patch-wise LPIPS（PLPIPS）衡量缓存生成图像与全推理图像的感知距离；2）Quality项：HPSv2奖励模型打分提升生成质量。组合为L_image(s) = d(x_cache, x_full) - α_iq R(x_cache)。加上熵正则项λ_entropy log p_θ(s)防止策略坍塌。
- **优化**：使用REINFORCE算法，并采用leave-one-out（LOO）基线降低方差。每次训练从预采样的噪声-全推理图像对中采样，并随机采样预算k，计算n个调度样本的损失梯度更新MLP参数。
- **推理时**：直接取Gumbel-Top-k的确定性版本（去除噪声），选择logits最大的k个步骤作为调度。

### 论文的主要结论与发现

1. ReCache在几乎所有设置下均优于对应的手工调度基线，尤其在低预算（k=7）下改善显著。
2. 在FLUX上，5×FLOPs降低时LPIPS比DiCache降低31%（0.456→0.316）；在Wan2.1上约2.6×加速时LPIPS降低65%（0.480→0.169），VBench提升7%（70.4→76.0）。
3. 学习到的调度呈嵌套性：低预算的步骤集合是高预算的子集，表明步骤重要性排序基本预算不变性。
4. 预算感知MLP略优于独立训练各预算的模型，且单个模型覆盖范围更广。
5. 跨模型迁移仍有效（从Wan2.1到HunyuanVideo），说明策略学到了去噪轨迹的通用结构。
6. 组合骨干步数更少（如N=25）的轨迹时，ReCache仍能进一步提升。

### 优点

- **创新性**：将缓存调度问题转化为可微的预算感知RL问题，首次实现用户直接指定计算预算，且无需标注数据。
- **兼容性**：与多种现有缓存机制（直接重用、预测）相兼容，只需替换调度即可提升性能。
- **效率**：轻量级MLP仅约100K参数，训练后推理时无额外开销。
- **实验严谨**：在多种模型、多种缓存机制、多种预算下进行系统比较，消融实验充分，跨模型迁移验证了泛化性。
- **结果显著**：在极低预算下大幅缩小与全推理的差距，且提升了人类偏好指标。

### 不足与局限

- **低步数限制**：在1–4步的极低缓存预算下，重用点之间间隔过大，缓存特征信息量不足，所有特征缓存方法均收益有限。

- **安全与双重用途**：论文自身指出加速可能被滥用于生成有害内容，需配合出处工具和访问控制。
- **实验未覆盖所有架构**：未在SDXL、Stable Diffusion 3等U-Net架构上验证，但理论上可推广。
