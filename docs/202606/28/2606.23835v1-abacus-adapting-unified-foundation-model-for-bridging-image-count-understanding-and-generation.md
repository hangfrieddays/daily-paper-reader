## 摘要
ABACUS是一个统一的视觉-语言模型，无需任何特定基准训练即可处理物体计数、人群计数、指代表达计数以及计数忠实图像生成。我们的模型基于现有的3B参数统一基础模型，并通过三项关键创新适配了物体定位任务：基于物体性地图的密度感知自适应缩放用于空间定位；通过GRPO的边界感知计数策略以消除裁剪边界误差；以及一种循环一致的GRPO策略，其中理解分支对生成的输出进行自我批评，无需任何外部标注即可弥合理解与生成之间的差距。ABACUS在七个基准测试中取得了最先进的结果，超越了特定任务专家模型和更大的通用模型。

## Abstract
ABACUS is a unified vision-language model that handles object counting, crowd counting, referring-expression counting, and count-faithful image generation without any benchmark-specific training required. Our model is built on existing 3B-parameter unified foundation model and is adapted for object localization tasks using three key innovations: density-aware adaptive zooming with objectness maps for spatial grounding; a boundary-aware count policy via GRPO to eliminate crop-boundary errors; and a cycle-consistent GRPO strategy where the understanding branch self-critiques generated outputs, closing the understanding-generation gap without any external annotations. ABACUS achieves state-of-the-art results across seven benchmarks, outperforming both task-specific specialists and larger generalist models.

## 1. 核心问题与整体含义（研究动机和背景）

- **背景**：物体计数（如人群、物体、指代表达计数）和计数条件图像生成是计算机视觉中互为补充的两个任务。然而，现有方法长期被孤立研究：计数任务依赖专用架构（密度图回归、检测头等），生成任务中扩散模型缺乏计数保真机制，导致生成的图像中物体数量不准确。
- **核心矛盾**：统一多模态模型（UMM）尝试用一个共享参数空间处理两种任务，但存在**协同鸿沟**（synergy gap）：同一个模型能正确计数却无法生成准确数量的物体。同时，现有的MLLM在密集场景中计数能力弱，无法为生成分支提供可靠监督。
- **研究目标**：提出一个单一统一模型，无需任何基准特定训练，同时完成物体计数、人群计数、指代表达计数和计数忠实的图像生成，在零样本设定下达到甚至超越专用模型。

## 2. 方法论：核心思想、关键技术细节

- **总体架构**：基于UniLIP-3B基础模型（InternViT编码器 + Qwen2语言骨干 + SANA扩散Transformer + DC-AE解码器），通过三个关键创新适配：

### 2.1 密度感知自适应缩放（Density-aware Adaptive Zooming）
- **问题**：MLLM在稀疏区域计数更可靠，密集区域易失败。
- **方案**：使用冻结的GroundingDINO-T骨干 + 轻量MLP作为密度分类器，将图像分为“稀疏”/“密集”。密集区域递归分割成2×2子区域（最大深度γ=3），直到子区域密度下降或达到最小分辨率。每个子区域独立由MLLM计数，结果聚合为全局计数。

### 2.2 物体性地图注入（Infusing Objectness in MLLM）
- **问题**：MLLM缺乏精确空间定位能力，易发生虚假记忆。
- **方案**：从MLLM的多头自注意力（MHSA）层中分解出每个头对视觉token的贡献，经学习到的仿射对齐得到空间残差，其L2范数作为物体性分数。同时，从最终生成token到所有视觉位置的交叉注意力权重平均得到空间注意力分布。通过高斯平滑的真实点标注作为监督，定义物体性正则化损失 L_obj，鼓励模型内化实例感知的空间结构。

### 2.3 边界感知计数策略（Boundary-aware Count Policy via GRPO）
- **问题**：自适应缩放将物体置于裁剪边界，导致重复计数或遗漏。
- **方案**：将密集图像分割为2×2四象限，每个对象被分类为内部、边缘或边界。策略π_θ输出结构化计数，确保每个对象只归属于一个象限。使用三重嵌套奖励（局部精度、边界一致性、全局一致性）通过GRPO进行后训练，奖励函数为 ∆r = exp(-|pred-GT|/(GT+ε))，组内优势计算后更新策略，并加入KL惩罚防止奖励黑客。

### 2.4 循环一致GRPO生成增强（Cycle-consistent GRPO for Generation）
- **问题**：生成分支独立训练导致计数不忠实。
- **方案**：理解分支冻结为计数模型。给定计数条件prompt，生成分支采样K个候选图像；理解分支统计每个候选中的目标数量，计算计数偏差奖励 R_cnt；结合美学评分器 S_aes 得到总奖励 R=λc R_cnt + λa S_aes。通过GRPO更新生成分支的LoRA，理解分支固定不变。该闭环使生成分支逐渐产生忠实计数的图像，同时理解分支在生成分布上不断锐化奖励信号。

### 2.5 三阶段训练策略
1. **阶段1（理解分支训练）**：使用密度感知缩放图像和 L = L_SFT + L_obj 微调MLLM（LoRA），然后执行边界感知GRPO后训练。生成分支冻结。
2. **阶段2（连接器训练）**：理解分支冻结，训练连接器对齐MLLM输出特征与DiT条件空间。
3. **阶段3（生成分支训练）**：连接器和DiT在计数条件生成数据上SFT，然后执行循环一致GRPO后训练，仅更新生成分支LoRA。
