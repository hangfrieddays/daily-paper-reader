## 摘要
我们提出了Qwen-Image-2.0-RL，这是一个后训练流程，应用基于人类反馈的强化学习（RLHF）和同策略蒸馏（OPD）来提升Qwen-Image-2.0扩散模型的视觉质量和指令遵循能力。为了提供可靠的奖励信号，我们通过使用逐点评分范式和思维链推理微调视觉语言模型，构建了任务特定的复合奖励模型。对于文本到图像生成，奖励模型覆盖对齐度、美学和人像保真度维度。对于图像编辑任务，奖励系统关注指令遵循准确性和人脸身份保留。基于此奖励系统，我们开发了一个可扩展的基于GRPO的RL训练框架，融合了混合无分类器引导（CFG）策略以保留预训练知识，通过组内奖励范围过滤进行提示整理，以及每类奖励权重校准。为了合并T2I和编辑任务的专门化RL策略，我们提出将同策略蒸馏作为最终训练阶段，通过轨迹级速度匹配将多个教师模型整合到一个学生模型中。大量评估表明，Qwen-Image-2.0-RL在Qwen-Image-Bench上获得了57.84的总分（比基础模型高2.61），在文本到图像竞技场中获得1193的Elo评分（+78），在图像编辑竞技场中获得1349的Elo评分（+93），在美学质量、提示遵循和编辑准确性方面均表现出一致的提升。

## Abstract
We present Qwen-Image-2.0-RL, a post-training pipeline that applies reinforcement learning from human feedback (RLHF) and on-policy distillation (OPD) to improve both the visual quality and instruction-following capability of the Qwen-Image-2.0 diffusion model. To provide reliable reward signals, we construct task-specific composite reward models by fine-tuning vision-language models with a pointwise scoring paradigm and chain-of-thought reasoning. For text-to-image generation, the reward models cover alignment, aesthetics, and portrait fidelity dimensions. For image editing tasks, the reward system addresses instruction-following accuracy and face identity preservation. Building on this reward system, we develop a scalable GRPO-based RL training framework, incorporating a hybrid classifier-free guidance (CFG) strategy to preserve pre-trained knowledge, prompt curation via intra-group reward range filtering, and per-category reward weight calibration. To merge the task-specialized RL policies for T2I and editing, we propose on-policy distillation as the final training stage, which consolidates multiple teachers into a single student model through trajectory-level velocity matching. Extensive evaluation shows that Qwen-Image-2.0-RL achieves 57.84 overall score on Qwen-Image-Bench (+2.61 over the base model), Elo ratings of 1193 in text-to-image arena (+78) and 1349 in image edit arena (+93), demonstrating consistent gains in aesthetic quality, prompt adherence, and editing accuracy.

- **背景**：RLHF（基于人类反馈的强化学习）已在语言模型中成功对齐人类偏好，但将其扩展到扩散模型面临三大挑战：
    1. **奖励信号设计**：需要覆盖不同任务（T2I 生成与图像编辑）的多维质量维度（全局美学、提示对齐、人像保真、编辑指令遵循、身份保持等）。
    2. **可扩展的 RL 训练**：现有 RL 框架多在 LoRA 设置下验证，全参数、多奖励、多任务的大规模训练尚待探索。
    3. **策略合并**：实际部署需要将任务专用的 RL 策略融合为单一模型，而不牺牲各任务的质量。
- **意义**：本文提出完整的后训练管道（RLHF + 同策略蒸馏），显著提升 Qwen‑Image‑2.0 的视觉质量和指令遵循能力，并统一支持 T2I 和编辑任务。

## 2. 论文提出的方法论
- **核心思想**：先通过点状评分范式训练 VLM 作为复合奖励模型，再基于 GRPO 对扩散模型进行任务专用的 RL 优化（T2I 和编辑分别训练），最后用同策略蒸馏（OPD）合并为单一模型。
- **关键技术细节**：
    - **奖励建模**：
        - 采用**点状评分范式**（给每张图像打 1-5 分）并辅以思维链（CoT）推理，作者经验发现它优于成对排名损失。
        - T2I 奖励包含三个层次：
            - **对齐奖励**（语义对应，优先于美学）
            - **美学奖励**（构图、照明、纹理）
            - **人像奖励**（面部吸引力、手掌细节等）
        - 图像编辑奖励包含：
            - **指令遵循奖励**（分解核心编辑需求并评估执行程度）
            - **人脸身份一致性奖励**（基于嵌入的专门模型）
    - **RL 训练框架**（基于 GRPO）：
        - **混合 CFG 策略**：在采样（rollout）时使用 CFG 以利用预训练知识，在策略优化目标中**排除**无条件分支，兼顾稳定性与能力保留。
        - **异步奖励管道**：将奖励评分部署为远程 API，通过后台线程异步提交，隐藏 I/O 延迟。
        - **多奖励优势计算**：对每个奖励进行组内均值-标准差归一化，然后加权求和，避免单一维度主导。
        - **任务特定优化**：
            - 时间步采样：只选一部分步数（尤其高噪声步）进行训练，防止奖励快速过拟合。
            - 提示过滤：对每个提示计算组内奖励范围，仅保留范围大于阈值的提示（提供有效优化信号）。
            - 每类奖励权重校准：按语义类别（人像、风景、排版等）分配不同奖励权重。
    - **同策略蒸馏（OPD）**：
        - 目标：将 T2I 教师和编辑教师合并为一个学生模型。
        - 学生用自己的轨迹采样，学习匹配任务对应教师的**速度场**：
            \[
            \mathcal{L}_{OPD} = \mathbb{E}\left[ \sum_{n=1}^{N} \|v_\theta(x_{t_n}, t_n, c) - v_{\theta^*}(x_{t_n}, t_n, c)\|^2 \right]
            \]
        - 基于 Wasserstein‑2 距离的上界推导，确保分布匹配。
        - 教师使用 CFG 预测，学生无 CFG，蒸馏后学生再启用 CFG。
        - 对比混合 RL（Mix‑RL）直接联合优化，OPD 避免任务冲突，效果更好。

## 7. 优点
- **系统完整性**：从奖励建模、RL 训练到策略合并，完整解决了扩散模型后训练的关键问题。
- **奖励设计精细**：T2I 的三层递进式奖励（对齐→美学→人像）和编辑的双重奖励（指令+身份）针对性强。
- **混合 CFG 策略**：创新性结合 CFG 在采样中的应用与在训练目标中的排除，既稳定又保留知识。
- **异步管道**：通过异步奖励请求降低训练延迟，适合多奖励大规模训练。
- **OPD 机制**：利用 Wasserstein‑2 上界推导损失，理论扎实；动态教师加载节省显存；避免多任务 RL 优化冲突。
