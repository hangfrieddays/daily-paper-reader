## 摘要
从自然语言指令生成可缩放矢量图形（SVG）代码是一项开放式任务，不存在绝对的视觉真值，这使得评估和策略优化都缺乏可靠的信号。在自然图像上校准的标量指标（CLIP、Aesthetic）难以迁移到风格化矢量内容，且将其复用为强化学习奖励会引发奖励破解。我们通过基于评分细则的评分来应对这两个局限。我们首先通过实证表明，使用多维度评分细则提示视觉语言评判模型，其与人类判断的相关性远高于标量指标，无论是在样本间还是指令内均如此。基于这一发现，我们提出 RULER（用于强化学习的实例感知评分细则奖励），它将每条指令转换为一个实例感知的六条目评分细则，涵盖语义、视觉和风格维度；评判 VLM 对渲染出的 rollout 逐项评分，加权后的满足度构成细粒度奖励，并通过组相对策略优化进行优化。由于评分细则仅从文本推导而来，RULER 既不需要配对的 SVG 真值，也不需要人类偏好标签。在 MMSVG-Illustration 和 MMSVG-Icon 上，RULER 将评分细则分数从 0.432/0.395 提升至 0.693/0.683，超过专门的 SVG 专家模型，并媲美规模大得多的 DeepSeek-V3；消融实验表明，评分细则设计是面向开放式 SVG 生成的强化学习中的有效杠杆。项目页面见 https://hangyuran.github.io/RULER/。

## Abstract
Generating Scalable Vector Graphics (SVG) code from natural-language instructions is an open-ended task without absolute visual ground truth, leaving both evaluation and policy optimization without a faithful signal. Scalar metrics (CLIP, Aesthetic) calibrated on natural images transfer poorly to stylized vector content, and reusing them as RL rewards triggers reward hacking. We address both limitations with rubric-based scoring. We first establish empirically that prompting a vision-language judge with a multi-axis rubric correlates with human judgments far better than scalar metrics, both across samples and within instructions. Building on this finding, we introduce RULER (Instance-aware Rubric Rewards for Reinforcement Learning), which converts each instruction into an instance-aware rubric of six items spanning semantic, visual, and stylistic axes; a judge VLM scores rendered rollouts item-by-item, and the weighted satisfactions form a fine-grained reward optimized via Group Relative Policy Optimization. Because the rubric is derived from text alone, RULER requires neither paired SVG ground truth nor human preference labels. On MMSVG-Illustration and MMSVG-Icon, RULER lifts the rubric score from 0.432/0.395 to 0.693/0.683, surpassing dedicated SVG specialists and matching the substantially larger DeepSeek-V3, with ablations identifying rubric design as the active lever for RL on open-ended SVG generation. The project page is available at https://hangyuran.github.io/RULER/.

## 1. 核心问题与整体含义（研究动机与背景）

- **任务背景**：从自然语言指令生成可缩放矢量图形（SVG）代码是视觉代码生成的前沿方向。SVG 具有结构化、可执行、可控等特性，但生成任务本质上是**开放式**的——同一条指令可对应无数语义有效的渲染结果，**不存在绝对的视觉真值**。
- **两大瓶颈**：
  - **评估指标不可靠**：CLIPScore、Aesthetic、HPS 等标量指标在真实自然图像上校准，迁移到风格化矢量内容时表现很差，常给残缺 SVG 打出比忠实 SVG 更高的分，且与人类判断相关性弱。
  - **监督信号不忠实**：SFT 退化为对数据集模板的行为克隆，泛化差；而 RL 的效果高度依赖奖励函数，现有可用奖励正是上述不可靠指标，导致策略偏向"最容易刷高的信号"（奖励黑客），而非真正更好的生成。
- **整体含义**：论文主张用**基于评分细则（rubric）的评分**同时解决评估与训练两个问题，并证明"评分细则设计"才是开放式 SVG 强化学习的有效杠杆。

## 2. 方法论

- **核心思想**：先用实证确立"多轴评分细则评分"是更可靠、更贴近人类判断的评估原语，再将其改造成 RL 的细粒度奖励。
- **实证基础**：收集 3 个能力不同模型（Claude-Opus-4.6、Qwen3-32B、Qwen3-8B）各 300 个、共 **900 个**人工标注 SVG 样本。评分细则评分达到样本级 Spearman ρ = 0.7929、成对排序一致性 Goodman-Kruskal γ = 0.7574，显著优于 Aesthetic（0.6051 / 0.5465）与 CLIP（0.5518 / 0.5295）。
- **MDP 形式化**：指令 Q → 策略 πθ 自回归生成 SVG 序列 Y → 渲染引擎 E 得到图像 I_gen = E(Y) → 计算奖励 R(·)。核心难点在于奖励函数设计而非优化机制。
- **实例感知评分细则生成**：
  - 由前沿模型 M_rub（如 Claude-Opus-4.6）**仅凭文本指令**生成 6 条目评分细则 C_Q = {(c_k, w_k)}_{k=1}^6。
  - 三大轴、固定权重 (5,5,5,4,5,5)：
    - **语义保真**：概念可读性、主要组件与辨识线索；
    - **视觉质量**：轮廓与形态精修、构图与画布设计；
    - **渲染风格**：渲染完成度与工艺洁净度、风格统一与设计趣味。
  - 条目按"设计意图"而非精确像素/路径约束描述，保持开放式解空间，避免退化为重建清单。
  - 生成过程先产出一个"理想 SVG"作为质量目标，但**不**作为 RL 评分的参考真值。
- **奖励计算**：评判 VLM M_judge（Qwen3-VL-8B，冻结）对渲染图逐项独立打分 s_k ∈ [0,1]，奖励为归一化加权平均：R(I_gen) = Σ w_k s_k / Σ w_k。
- **策略优化**：采用 **GRPO**。每条指令采样 G=8 个 rollout，组内归一化得到优势 A_i = (R_i − mean)/ (std + ε)，再最大化裁剪代理目标 L_GRPO（含重要性比 ρ_i 与 clip 操作）。
- **关键特性**：评分细则仅由文本推导，**无需配对 SVG 真值，也无需人工偏好标签**，可扩展到任意无标注指令集。

## 3. 实验设计

- **数据集 / 场景**：

  - 训练数据：从两 benchmark 训练集采样，经结构与质量过滤（理想 SVG 奖励需 ≥ 0.9），最终 **19,531（Icon）+ 11,206（Illustration）= 30,737** 条 prompt–rubric 对。
- **对比方法（三类）**：
  - 扩散优化类：VectorFusion、SVGDreamer；
  - 基础大模型：Qwen3-8B、Qwen3-32B、DeepSeek-V3；
  - SVG 专家模型：IconShop、JanusCoder-8B、OmniSVG-8B。
- **指标**：Tokens（效率）、CLIP、Aesthetic、HPS，以及作者引入的 **Rubric 分数**（由 GPT-5-mini 作为独立 VLM 评判，用统一通用评分细则）作为主指标。
- **奖励设计对比（RQ2）**：Zero-Shot、C+A+H RL（CLIP+Aesthetic+HPS 标量奖励）、Universal Rubric RL（统一通用评分细则）、RULER（实例感知）。
- **消融（RQ3）**：去掉语义轴 / 视觉轴 / 渲染轴，以及更严格的 Rubric-S（五项 + 固定文本提示惩罚项，权重 −2）。
- **鲁棒性（RQ4）**：Qwen3-4B 与 8B 两种策略规模；Claude-Opus-4.6 与 GPT-5.5 两种评分细则生成器；5 个随机种子重复。
- **人工评估**：
  - 指标对齐研究：900 样本，10 名标注者 + 3 名校验者；
  - 最终输出偏好研究：150 prompts × 5 baseline = 750 对成对比较，3 名标注者，盲测、随机左右顺序。

## 6. 主要结论与发现

- **评分细则评分显著优于标量指标**：与人类判断的相关性和排序一致性都明显更高，是可靠的开放式 SVG 评估器。
- **主结果**：RULER 将 Rubric 分数从 0.432/0.395（Qwen3-8B 基线）提升至 **0.693/0.683**（Illustration/Icon），超越所有基线家族（含专用 SVG 专家），并媲美远更大的 DeepSeek-V3，且 token 开销远低于扩散优化方法。
- **人工偏好验证**：对 5 个基线的非平局胜率均超 50%，从 53.3%（vs VectorFusion）到 96.5%（vs JanusCoder）。
- **奖励设计是关键杠杆**：
  - 通用评分细则 RL 稳定提升（0.660 / 0.591），但缺少实例粒度；
  - C+A+H 标量奖励出现严重奖励黑客——Aesthetic 被刷到 6.697，但 CLIP 下降、Icon 上 Rubric 甚至跌到 0.262（低于零样本），并生成 6.3k token 的密集冗余笔画。
- **消融结论**：三轴互补，去除**视觉质量轴**下降最大（0.693→0.580），其次渲染轴（→0.599），语义轴影响最小（→0.623）；**Rubric-S** 触发"文本提示捷径"黑客行为，Rubric 跌至 0.536，说明"轴的互补性至少与评分严格程度同等重要"。
- **鲁棒性**：收益在 4B/8B 策略规模、Claude/GPT 两种评分细则生成器下均保持稳定。

## 7. 优点

- **问题定位准确**：清晰揭示标量指标在风格化矢量内容上的失准与奖励黑客机制，并用数据（900 人工标注）支撑动机。
- **无需真值与偏好标签**：评分细则仅从文本推导，天然适配一对多的开放式生成，可扩展到任意无标注指令集。
- **奖励设计细腻**：实例感知 + 多轴分解 + 逐项连续打分，把模糊的视觉判断转化为可验证的子目标，并天然适配 GRPO 的组内相对优势。
- **实验严谨度高**：盲测人工偏好研究、5 次种子重复、两种评分细则生成器与两种策略规模的交叉验证、统一的渲染与评判管线，增强了结论可信度。
- **消融有洞察力**：不仅验证各轴必要性，还通过 Rubric-S 暴露"更严格 ≠ 更好"这一反直觉但重要的设计原则。
- **效率对比清晰**：指出 RULER 单次自回归生成即超过需要逐 prompt 迭代优化的扩散方法（后者平均 72.1 分钟/样本）。

## 8. 不足与局限

- **依赖外部模型**：框架同时依赖前沿模型生成评分细则、VLM 评判打分，奖励质量会继承二者的偏见、偏好与失效模式，评判可能高估表面线索、低估细微风格品质，尤其在分布外 prompt 上。
- **计算成本高**：每个训练步需渲染所有采样 SVG 并逐条查询评判 VLM，远贵于 CLIP 或代码启发式等轻量奖励，可能限制向更大模型、更长 rollout、更广超参搜索的扩展。
- **质量分解的固有偏置**：将质量固定分解为语义/视觉/风格三轴虽然在本 benchmark 有效，但未必覆盖所有合法艺术意图或领域特定偏好；评分细则设计本身敏感（Rubric-S 即反例）。
- **评估覆盖局限**：训练与测试 prompt 同属一个 benchmark 分布，作者明确不视其为 OOD 评测；主指标 Rubric 由 GPT-5-mini 评判，与训练所用 Qwen3-VL-8B 不同，但仍可能引入评判模型偏好。
- **资源信息不完整**：未报告具体训练时长或总 GPU 小时，成本透明度有限。
- **未来方向**：交互式、人类可引导、领域自适应的评分细则设计仍待探索。
