## 摘要
视觉奖励模型对于评估和改进视觉生成模型至关重要，然而现有方法通常将任务条件和候选输出直接映射为标量奖励，使得每个具体案例中应当评估什么变得隐含不明确。我们提出 Think Before You Score，一种在评判候选表现优劣之前，先明确每个案例中关键评估要素的范式。遵循这一原则，我们提出思维奖励模型（Thinking Reward Model, TRM），它构建案例自适应评分标准，执行评分标准引导的评估，并产生细粒度的逐点奖励。我们进一步观察到，传统成对偏好优化可能导致分数极化，并引入成对双组相对策略优化（Pairwise Dual-Group Relative Policy Optimization, PD-GRPO），它利用成对监督提升奖励区分度，同时保留细粒度的逐点评分。在图像生成与编辑奖励建模基准上的大量实验表明，TRM 在开源奖励模型中达到最先进性能，同时与专有替代方案相比仍极具竞争力。此外，将 TRM 用作强化学习的奖励可一致地改进多种视觉生成模型，表明其细粒度、案例自适应的奖励能够转化为视觉生成的有效优化信号。

## Abstract
Visual reward models are essential for evaluating and improving visual generation models, yet existing approaches typically map task conditions and candidate outputs directly to scalar rewards, leaving implicit what should be evaluated for each individual case. We introduce Think Before You Score, a paradigm that explicitly determines what matters for each case before judging how well the candidate performs. Following this principle, we propose the Thinking Reward Model (TRM), which formulates case-adaptive rubrics, performs rubric-guided assessment, and produces fine-grained pointwise rewards. We further observe that conventional pairwise preference optimization can induce score polarization, and introduce Pairwise Dual-Group Relative Policy Optimization (PD-GRPO), which leverages pairwise supervision to improve reward discrimination while preserving fine-grained pointwise scoring. Extensive experiments on image generation and editing reward-modeling benchmarks demonstrate that TRM achieves state-of-the-art performance among open-source reward models while remaining highly competitive with proprietary alternatives. Moreover, using TRM as a reward for reinforcement learning consistently improves diverse visual generation models, demonstrating that its fine-grained, case-adaptive rewards translate into effective optimization signals for visual generation.

- **整体含义**：论文提出 **“Think Before You Score”** 范式，即奖励模型应先为当前案例生成自适应评分细则，再进行细则引导的评估，最终输出细粒度逐点奖励。该范式试图把隐式的“条件→分数”映射，转化为结构化、可解释、案例自适应的评估过程。

## 2. 方法论：核心思想与关键技术细节

### 2.1 核心思想

- 将奖励建模统一为 **R → J → H → s** 的过程：
  - **R**：案例自适应评分细则（case-adaptive rubric），明确“要检查什么”。
  - **J**：细则级检查与判断，每个原子细则输出二元 Yes/No 判断。
  - **H**：维度级评估，汇总细则判断，形成维度级分析。
  - **s**：最终逐点奖励分数。
- 统一维度结构：
  - 图像生成与图像编辑共享：**Prompt Alignment / Instruction Following**、**Visual Quality**。

### 2.3 PD-GRPO：成对双组相对策略优化

- **问题动机**：
  - 传统 Bradley–Terry（BT）式成对偏好优化虽然能保留逐点评分接口，但会持续奖励扩大分数差距，即使偏好顺序已经正确。
  - 这会导致 **分数极化**：偏好样本分数不断升高，非偏好样本分数不断降低，绝对分数失去良好校准。
- **PD-GRPO 设计**：
  - 对每个偏好对 `(x+, x−)`，独立采样 N 个逐点评估响应：
    - `G+ = {y+_1, ..., y+_N}`，来自偏好候选。
    - `G− = {y−_1, ..., y−_N}`，来自非偏好候选。
  - 计算两组平均分：
    - `μ+ = mean(G+)`
    - `μ− = mean(G−)`
  - 构造偏好奖励：
    - 对 `y ∈ G+`：`r_pref(y) = I[s(y) − μ− > m]`
    - 对 `y ∈ G−`：`r_pref(y) = I[μ+ − s(y) > m]`
    - 其中 `m` 为要求的分离边际。
  - 一旦满足边际，奖励变为常数，不再奖励继续扩大分数差距，从而缓解分数极化。
- **策略优化**：
  - 两组仅用于奖励构造；策略优化时合并为 `G = G+ ∪ G−`。
  - 计算组相对优势：`A_k = (R_k − μ_G) / (σ_G + ε)`。
  - 使用标准裁剪的组相对目标，并加入 KL 正则。
  - 推理时两个候选仍独立评估，保持逐点推理接口。
- **奖励形式**：
  - `R(y) = r_pref(y) + λ_fmt r_fmt(y)`。
  - `r_fmt` 为格式奖励，鼓励输出有效结构化结果。
- **难度感知偏好对**：
  - 用奖励差距作为偏好难度代理：差距大→简单，差距小→困难。
  - 分为 easy、medium、hard，并平衡采样。
- **超参数**：
  - 图像编辑：`m = 0`。
  - 图像生成：`m = 0.05`，因为存在更多平局和近似平局。
  - 每候选采样 8 个 rollout，共 16 个 rollout/偏好对。

  - 相比 EditScore-72B，TRM 在训练中保留更大奖励方差，提供更具区分度的组相对优势信号。
- **逐点评分的优势**：
  - 逐点评分支持更大 rollout 组，计算成本随组大小线性增长，而成对比较为二次增长。
  - 成对监督仅用于训练，推理时仍保持逐点接口。

## 7. 优点

- **方法创新性强**：
  - 明确提出“先确定评什么，再评分”的奖励建模范式，将案例自适应评分细则引入视觉奖励模型。
  - 统一图像生成与图像编辑的评估过程，同时保留任务特定维度。
- **结构化监督质量高**：
  - 两阶段人机协同标注，兼顾细则覆盖性、原子性和分数校准。
  - 数据规模较大，覆盖多任务、多模型、多质量水平。
- **优化目标设计合理**：
  - PD-GRPO 针对 BT 式偏好优化的分数极化问题，设计硬边际双组相对奖励，既利用成对监督，又保持逐点评分。
  - 难度感知偏好对增强细粒度区分能力。
- **实验较全面**：
  - 同时验证奖励建模性能和下游 RL 优化效果。
  - 包含多基准、多模型、多规模、消融、受控对比、一致性和 tie-aware 分析。
- **参数效率突出**：
  - 9B TRM 在多个编辑基准上超过 72B EditScore，显示较强性价比。
- **可解释性与可扩展性**：
  - 输出结构化 JSON，包含细则、维度摘要、评分理由和最终分数。
  - 范式可扩展到 T2V、TI2V、V2V、World Model 等更广泛视觉生成任务。

## 8. 不足与局限

- **算力信息不完整**：
  - 未明确 GPU 型号、总训练时长、总 GPU 小时数。
  - 难以精确评估训练成本和复现门槛。
- **评估范围仍有边界**：
  - 主要聚焦图像生成和图像编辑，虽然提到可扩展到视频和世界模型，但未实际验证。
  - 图像生成奖励建模基准数量相对编辑较少，主要依赖 GenAI-T2I 和 MMRB2-T2I。
- **逐点评分的固有局限**：
  - 逐点评分可能产生平局，主结果排除平局后准确率可能偏高。
  - 虽然补充了 tie-aware 结果，但逐点分数分辨率有限，对极细粒度质量差异的区分仍受评分尺度限制。
- **成对监督与推理接口的差异**：
  - 训练使用成对偏好，推理使用逐点评分；两者之间存在一定目标错位。
  - PD-GRPO 虽缓解极化，但硬边际奖励可能丢失部分偏好强度信息。
- **数据与标注偏差风险**：
  - 依赖教师模型生成细则和分数，再人工校准，可能继承教师模型偏差。
  - 图像生成数据中，作者也提到单一教师模型对相似质量候选区分有限，需引入其他评估模型校准，说明标注一致性仍具挑战。
  - 数据平衡虽已进行，但不同任务、模型来源和难度层的分布可能仍影响泛化。
- **对比公平性需谨慎解读**：
  - 部分基线模型规模更大或为专有模型，TRM 以 9B 取得优势，虽体现效率，但训练数据、提示和评估协议差异可能影响绝对可比性。
  - 图像编辑消融中 TRM 与 EditScore-72B 的对比虽控制训练设置，但奖励模型规模和预训练来源不同。
- **应用限制**：
  - 作为 MLLM 奖励模型，推理成本高于轻量回归奖励模型；论文通过异步奖励和前缀缓存优化，但未给出端到端吞吐和延迟的完整量化。
  - 依赖结构化输出格式，若解析失败或格式错误，可能影响 RL 稳定性。
  - 对中文、多语言、海报、文本渲染等场景虽有覆盖，但更广泛文化、审美和主观偏好差异仍需进一步验证。
