## 摘要
多主体图像生成需要相应的奖励机制，用以验证所要求的属性、动作和关系是否在指定的参考主体上成立。仅有主体出现并不足以说明正确的主体参与了所要求的交互。我们提出参考绑定的 Visual Jev 奖励，将这些视觉判定转化为生成器的训练信号。每个与主体相关的问题只有在所要求的条件与相关参考身份同时成立时才获得正标签。我们离线构建固定问题，以二值监督训练一个 Qwen3.5-4B 验证器，并直接从其语言模型头读取 Yes 概率。这些概率的均值构成 GRPO 奖励，同时保留各个独立判定以供检查。在人工选出的 897 个任务的 MICo-Bench 子集上，使用 200 个 MICo-150K 训练任务和 30 次更新，该框架将 GPT-5.4 的综合得分从 41.78 提升至 52.50；直接使用 27B 奖励则得到 51.84。每种奖励仅在一次 GRPO 运行中测试，且离线人工评估未能确立其相对于直接评分的统计显著优势。本研究给出了将 Visual Jev 作为多主体图像生成的参考绑定奖励的初步实现与评估。

## Abstract
Multi-subject image generation requires rewards that verify whether requested attributes, actions, and relations hold for the specified reference subjects. Subject presence alone does not establish that the correct subjects participate in a requested interaction. We present reference-bound Visual Jev rewards that turn these visual decisions into generator training signals. Each subject-related question receives a positive label only when the requested condition and the relevant reference identities hold jointly. We construct fixed questions offline, train a Qwen3.5-4B verifier with binary supervision, and directly read Yes probabilities from its language-model head. Their mean supplies a GRPO reward while retaining individual judgments for inspection. Using 200 MICo-150K training tasks and 30 updates, the framework raises a GPT-5.4 composite score from 41.78 to 52.50 on a manually selected 897-task MICo-Bench subset; direct 27B rewards yield 51.84. Each reward is tested in one GRPO run, and offline human evaluation does not establish a statistically significant advantage over direct scoring. The study provides an initial implementation and evaluation of Visual Jev as a reference-bound reward for multi-subject image generation.

## 1. 核心问题与整体含义
- **研究动机**：多主体图像生成需要把参考图像中的指定人物/物体与文本提示中的属性、动作、关系组合到新场景中。仅验证“主体是否出现”并不足够，因为模型可能让错误的主体参与交互，例如让参考人物抱着另一只狗，而参考狗站在旁边。
- **核心问题**：如何设计奖励，使其判断“指定参考主体是否正确参与了指定属性、动作和关系”，而不只是分别判断主体一致性和指令遵循。
- **整体含义**：论文将 Visual Jev 式“问题—答案概率”决策接口引入生成训练循环，提出 reference-bound Visual Jev 奖励。每个主体相关问题只有在“请求条件成立”且“相关参考身份正确”时才获得正标签。该奖励用于 GRPO 后训练多主体图像生成器，并保留原子级判定以便诊断。
- **背景脉络**：多图条件生成与 MICo-150K 等数据推进了多主体组合能力；Flow-GRPO、PSR 等证明奖励后训练有效；TIFA、DSG、AlphaGRPO 等用问题分解做细粒度验证。本文进一步强调：在多参考生成中，主体相关问题必须绑定“哪个参考主体”。

## 2. 方法论
- **核心思想**：把主体相关视觉条件写成参考绑定的原子问题，离线固定问题集；训练一个视觉验证器直接预测每个完整问题的满足概率；将这些概率聚合为图像级奖励，用于 GRPO 更新生成器。
- **任务定义**：给定文本提示 \(c\) 和有序参考图像 \(R=(r_1,\dots,r_M)\)，生成器 \(\pi_\theta\) 生成图像 \(x\)。目标是学习奖励 \(R_\phi(x,u)\)，其中 \(u=(c,R)\)，先训练验证器并固定 \(\phi\)，再优化生成器。
- **离线问题构造**：用 GPT-5.4 从提示和有序参考中构造固定问题集 \(Q(u)=G(c,R)=\{q_i\}_{i=1}^{N_u}\)。问题需满足：基于输入要求、包含完整主体引用与判断条件、覆盖主要要求并减少语义重复。候选生成前问题已固定，所有候选共享同一问题集。
- **身份依赖的正标签语义**：设 \(S_i\) 为问题 \(q_i\) 涉及的参考主体集合，\(I_s(x,R)\) 表示候选图像中对应主体是否匹配参考主体 \(s\)，\(C_i(x)\) 表示指定属性/动作/关系是否成立。则正标签为：
  \[
  y_i = C_i(x) \land \bigwedge_{s\in S_i} I_s(x,R)
  \]
  即：只有当指定条件与相关参考身份同时成立时，该问题才为正。身份约束只作用于该问题涉及的主体；不要求单独乘身份门控，而是在完整问题预测中直接学习。
- **Visual Jev 验证器实现**：使用 Qwen3.5-4B + LoRA + 二分类交叉熵训练。给定图像、参考和问题，从语言模型头读取 Yes/No logits，计算：
  \[
  p_i = \sigma(z_i^Y - z_i^N)
  \]
  即 Yes 相对支持度。验证器用 BCE 损失训练：
  \[
  L_V(\phi)=-\frac{1}{K}\sum_{n=1}^K [y_n\log p_n+(1-y_n)\log(1-p_n)]
  \]
  训练更新 LoRA 参数，保留语言模型输出头用于答案读取；训练后冻结验证器。
- **图像级奖励聚合**：对候选 \(x\) 和任务 \(u\)，验证器输出原子分数 \(p=(p_1,\dots,p_{N_u})\)，奖励为算术平均：
  \[
  R_\phi(x,u)=\frac{1}{N_u}\sum_{i=1}^{N_u} p_\phi(x,R,q_i)
  \]
  奖励在 [0,1] 内，各问题等权；保留各原子分数用于诊断。
- **GRPO 训练流程**：从官方 Qwen-Image-Edit-2511 初始化，加入 LoRA。对每个任务采样一组候选，用同一问题集和冻结验证器打分，计算组内相对优势，再执行 GRPO 更新。问题和验证器参数保持固定，只更新生成器 LoRA。
