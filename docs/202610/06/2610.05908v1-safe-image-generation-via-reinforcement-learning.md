## 摘要
近期的文本到图像（Text-to-Image, T2I）模型取得了显著的视觉图像生成性能，但它们仍可能生成 NSFW（Not-Safe-For-Work）内容，包括暴力或露骨图像。现有安全检查机制在很大程度上局限于生成前过滤（例如提示级文本分类器）或图像完全合成后的事后审核。然而，对抗攻击方法的作用空间要广泛得多。这种不平衡凸显了需要一种在生成过程中进行干预的安全机制。我们提出了一种生成中安全框架，该框架监测去噪轨迹，并从中间表示中检测新出现的 NSFW 信号。我们的方法不仅仅是检测 NSFW 生成，而是应用强化学习从 NSFW 提示生成安全图像。通过将生成中检测与可控引导相结合，即使 NSFW 信号在生成已经开始后才出现，我们的方法也能缓解不安全轨迹。实验结果表明，我们的方法在标准和对抗评估集上均持续优于现有安全图像生成方法，同时保持感知质量和提示保真度。代码将在接收后发布。

## Abstract
Recent Text-to-Image (T2I) models achieve remarkable visual image generation performance, but they can still generate NSFW (Not-Safe-For-Work) contents, including violent or explicit images. Existing safety checker mechanisms are largely confined to pre-generation filtering (e.g. prompt-level text classifiers) or post-hoc moderation applied after an image is completely synthesized. However, adversarial attack methods operate over a much broader space. This imbalance highlights the need for a safety mechanism that intervenes during the generation process. We propose an in-generation safety framework that monitors the denoising trajectory and detects emerging NSFW signals from intermediate representations. Rather than merely detecting NSFW generations, our method applies reinforcement learning to generate safe images from NSFW prompts. By coupling in-generation detection with controllable steering, our approach mitigates unsafe trajectories even when NSFW signals emerge after generation has already begun. Experiments results show that our method consistently outperforms existing safe image generation methods across both standard and adversarial evaluation sets, while preserving perceptual quality and prompt fidelity. Code will be released upon acceptance.

## 2. 方法论

### 2.1 核心思想
- 将预训练 T2I 模型的去噪过程视为**部分可观测马尔可夫决策过程（POMDP）**，冻结 T2I 模型，仅训练轻量级 actor-critic 干预策略，实现即插即用。
- 在每个探测时间步观察当前去噪状态，预测 NSFW 风险，并自适应决定干预方向与强度，单次干预会通过后续去噪步骤传播，重塑整条生成路径。

### 2.2 关键技术细节

**（1）NSFW 信号提取与潜空间安全探针**
- 由当前噪声潜变量 $z_t$ 和预测噪声 $\epsilon_\theta(z_t,t)$ 估计干净潜变量 $\hat{z}_0^{(t)}$，再经 VAE 解码得到像素级近似 $\hat{x}_0^{(t)}$。
- 使用 NudeNet 与 OpenAI Moderation API 组合为教师 NSFW 分数 $s_t$。
- 训练轻量 CNN 探针 $g_\phi(\hat{z}_0^{(t)},\tilde{t})$ 直接从潜空间预测 NSFW 分数，通过知识蒸馏从像素级教师管线学习，避免每次探测都做 VAE 解码和外部 API 调用。

**（2）安全引导噪声预测**
- 在 CFG 基础上定义三个噪声预测：无条件 $\epsilon_t^\emptyset$、提示条件 $\epsilon_t^c$、不安全概念条件 $\epsilon_t^u$，得到提示方向 $\Delta_t^c$ 与不安全方向 $\Delta_t^u$。
- 构造元素级二值掩码 $M_{t,j}$：仅保留提示方向与不安全方向**符号一致**且不安全信号幅度**超过阈值** $\tau_d$ 的分量，确保只抑制提示本身驱动的不安全成分。
- 不安全方向 $d_t$ 取提示与不安全方向幅度的逐元素最小值，保证抑制不超过提示自身贡献。
- 修正后的噪声预测为 $\tilde{\epsilon}_t = \epsilon_t^{base} - \kappa a_t d_t$，其中 $a_t \in [0,1]$ 为策略动作，$\kappa$ 为固定缩放因子。

**（3）奖励设计**
- **中间奖励**：$r_t = \lambda_s(t)(\hat{s}_{t+m}-\hat{s}_t) - \lambda_i C(a_t) - \lambda_d D(z_t,z_t^{base})$，分别奖励 NSFW 分数即时下降、惩罚干预成本、惩罚偏离基线轨迹；$\lambda_s(t)$ 随时间步接近末尾而单调递增。
- **终端奖励**：$r_0^{final} = \lambda_a A(x_0) - \lambda_u U(x_0) + \lambda_p S_{prompt}(x_0,c)$，分别对应 LAION 美学分、最终 NSFW 惩罚、CLIP 提示对齐分。
- 总奖励 $R_t$ 在最终时间步合并终端奖励，并通过折扣回报传播至所有早期步骤。

**（4）策略观测与动作**
- 观测 $o_t$ 由各通道的均值、标准差、均方根、绝对均值统计量，加上干预前 NSFW 分数 $\hat{s}_t$ 与归一化时间步 $\tilde{t}$ 构成。
- 动作 $a_t$ 从 Beta 分布 $\pi_\zeta(\cdot|h_t)$ 中采样，$a_t=0$ 表示不干预，$a_t=1$ 表示最大强度抑制。
- actor-critic 网络共享编码器为 MLP + GRU，GRU 维护隐藏信念状态 $h_t$，累积观测与干预历史，以应对部分可观测性。

**（5）训练目标**
- 使用 PPO 与 GAE，总损失为裁剪 actor 损失、值损失与熵奖励三项之和。

**（6）流匹配模型扩展**
- 将 $\epsilon$-预测替换为 SD v3.0 Transformer 的 velocity 场 $v_\theta$，干预机制不变：$\tilde{v}_t = v_t^{base} - \kappa a_t d_t$，由 FlowMatch Euler 调度器计算下一步潜变量；干净潜变量通过直接外推到 $\sigma'=0$ 估计。

## 6. 主要结论与发现

- 本文方法在**几乎所有设置下取得最低的 IP 与 EMI**，在对抗集上提升尤为显著。

## 7. 优点

- **主动生成中干预**：将安全防护从被动单阶段检查升级为轨迹感知的在线控制，能应对多阶段对抗攻击。
- **即插即用**：T2I 模型完全冻结，仅训练约 0.8–0.9M 参数的轻量策略，可跨扩散与流匹配架构部署。
- **密集信用分配**：分解为中间奖励与终端奖励，缓解扩散 RL 中稀疏奖励导致的信用分配难题。
- **语义精确的掩码机制**：仅抑制提示与不安全方向一致的分量，避免不必要的语义扰动，兼顾安全与提示保真。
- **质量保持设计**：终端美学奖励与干预成本惩罚共同作用，避免安全优化导致图像质量崩塌。
- **实验严谨性**：使用留出检测器 Q16、统计显著性检验、多种自适应攻击评估，验证结论的泛化性与鲁棒性。
- **GRU 信念状态**：显式建模部分可观测性，能检测生成中 NSFW 分数突增并累积干预历史。

- **奖励权重敏感且未充分消融**：$\lambda_s,\lambda_i,\lambda_d,\lambda_a,\lambda_u,\lambda_p$ 等多个超参数共同决定安全—质量权衡，论文未给出系统的敏感性分析，实际部署时的调参成本与迁移风险不明确。
- **时序泛化性存疑**：策略在固定的干预间隔（每 4–5 步）与固定步数（T=50/28）下训练，若更换调度器、步数或采样器，是否仍保持鲁棒性缺乏验证。
- **对抗评估偏“白盒化”**：生成中攻击与探针自适应攻击均假设攻击者了解干预机制与探针位置，虽提升了评估强度，但真实黑盒、查询受限或迁移式攻击下的表现仍待检验。

## 9. 可复现性与开放性

- **优点**：给出了优化器、学习率、episode 数、batch size、干预间隔、骨干版本与调度器等关键配置，参数量与探针规模也有说明，理论上具备复现基础。
- **不足**：未提供代码/模型权重链接，未报告随机种子与多次运行的方差，未说明教师检测器版本；训练总时长与 GPU 小时缺失，使算力门槛难以预估。
- **数据依赖**：训练与测试均以 I2P、COCO 为主，对抗集由四种公开攻击方法生成，若这些数据集或攻击实现更新，结论的可比性可能受影响。

## 10. 伦理与更广泛影响

- **正向价值**：为 T2I 内容安全提供了一种可插拔、低成本、跨架构的生成中防护范式，有助于平台在不重训大模型的前提下降低有害内容输出。
- **风险面**：安全过滤天然带有价值判断，若被用于过度审查或压制合法表达，可能产生寒蝉效应；同时“安全化”本身可能被滥用为规避检测的对抗研究起点。
- **双刃剑效应**：论文对生成中攻击与探针规避的详细分析，虽用于证明鲁棒性，但也可能为攻击者提供改进思路，需在开放与安全之间谨慎权衡。
- **公平性**：教师检测器对特定人群、文化语境或少数语言提示的偏差会被蒸馏进探针，可能导致对某些群体的差异化误判，论文未做偏见审计。

## 11. 对后续研究的启示

- **更细粒度的动作空间**：从单标量强度扩展为多概念、多维度的方向与强度联合控制，以应对纠缠型有害提示。
- **更鲁棒的安全表征**：结合多教师集成、主动学习或人类反馈，缓解对单一检测器的过拟合。
- **理论与收敛性分析**：将去噪 RL 的信用分配与策略优化纳入更严格的理论框架，理解密集奖励设计的必要条件。
- **统一安全—质量帕累托前沿**：显式建模安全与美学/对齐之间的权衡曲线，提供可调节的部署旋钮。
- **跨模态与跨架构泛化**：扩展到视频生成、3D 生成及更多流匹配/一致性模型，验证框架的普适性。

## 12. 总体评价

该论文的核心贡献在于**将 T2I 安全从“事后拦截/事前过滤”推进到“生成中轨迹控制”**，并用 RL 形式化了这一在线干预问题。其技术路线（冻结主干 + 轻量 actor-critic + 潜空间探针 + 掩码化安全方向 + 密集奖励）设计完整、模块清晰，实验在标准集、对抗集、生成中攻击、自适应攻击与留出检测器等多个维度展开，消融也较充分，结论具有较强说服力。方法在扩散与流匹配两类模型上的成功迁移，进一步提升了其通用性价值。

与此同时，论文的局限也较明显：安全性定义受制于外部检测器、动作空间表达能力有限、超参数与推理开销的工程代价、以及对抗评估的覆盖面与真实威胁模型之间仍有距离。总体而言，这是一项**方法创新性强、工程可落地性较好、但安全边界与泛化性仍需进一步刻画**的工作，为“生成过程安全”这一新兴方向提供了有价值的基线与研究框架。
