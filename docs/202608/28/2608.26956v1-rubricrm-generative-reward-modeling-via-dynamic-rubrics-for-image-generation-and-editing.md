## 摘要
奖励模型在对齐视觉生成模型中扮演关键角色，然而现有大多数视觉奖励模型使用单一标量分数或依赖无法适应不同指令的固定标准。这限制了可解释性和任务敏感性，尤其是在文本到图像生成和基于指令的图像编辑中，不同输入需要不同的评估维度。我们提出RubricRM，一种成对生成式奖励建模框架，它首先生成包含评估维度、权重和评分标准的输入特定评分标准，然后应用该评分标准对候选图像进行评分。我们使用两阶段训练流程为文本到图像生成和图像编辑训练专用的RubricRM模型：监督微调教会模型基于评分标准的评分范式，而GRPO则通过细粒度的维度级奖励进一步改进评分。在多个生成和编辑基准上的实验表明，尽管使用较小规模的骨干网络，RubricRM仍优于现有的专用奖励模型，并能与强大的专有MLLM评判者竞争。我们的模型、数据和代码可在https://github.com/zijiankan/RubricRM获取。

## Abstract
Reward models play an essential role in aligning visual generative models, yet most existing visual reward models use a single scalar score or rely on fixed criteria that cannot adapt to different instructions. This limits both interpretability and task sensitivity, especially for text-to-image generation and instruction-based image editing, where different inputs require different evaluation dimensions. We propose RubricRM, a pairwise generative reward modeling framework that first produces an input-specific rubric with evaluation dimensions, weights, and scoring criteria, and then applies the rubric to score candidate images. We train dedicated RubricRM models for text-to-image generation and image editing using a two-stage training pipeline: supervised fine-tuning teaches the model the rubric-based scoring paradigm, while GRPO further improves scoring through fine-grained dimension-level rewards. Experiments on multiple generation and editing benchmarks show that RubricRM outperforms existing specialized reward models and remains competitive with strong proprietary MLLM judges despite using smaller backbones. Our models, data, and code are available at https://github.com/zijiankan/RubricRM.

## 1. 论文的核心问题与整体含义（研究动机与背景）

现有视觉奖励模型在对齐图像生成与编辑模型中至关重要，但存在两大核心缺陷：

- **单一标量分数缺乏可解释性**：如 ImageReward、HPS v2/v3、PickScore、EditReward 等模型虽然在大规模偏好数据上训练，但最终只输出一个难以解释的分数。
- **固定评估标准无法适应不同指令**：不同指令天然要求不同的评估侧重点。例如，写实提示词应优先考虑物理合理性，而创意提示词则应更看重新颖性；图像编辑任务中，指令遵循、源图像保留与视觉质量之间的权衡也因指令而异。

为应对上述问题，论文提出 **RubricRM**（Rubric-based Reward Model），其核心思想是在指令与最终偏好决策之间引入一个**动态生成的评估 rubric（评分标准）** 作为中间协议。Rubric 明确规定了"评估哪些维度、每个维度权重多少、每个分数等级如何解释"，从而使评分过程既适配输入又具备可检查性。作者在文本到图像生成与指令式图像编辑两个任务上分别训练了专用模型，实验证明该框架超越了现有专用奖励模型，并以较小骨干网络取得了与强 MLLM 评判者相当的性能。

## 2. 论文提出的方法论

### 2.1 核心思想

RubricRM 将视觉奖励建模定义为一个**成对生成式任务**：给定指令（文本提示或编辑指令+源图像）与两个候选图像，模型在单次前向传播中完成两件事：

1. **生成动态 rubric**：包含任务意图分析、N 个原子评估维度 \(d_i\)、归一化权重 \(w_i\)（∑w_i=1）、以及每个维度的分级评分标准 \(L_i\)；
2. **基于 rubric 对候选图像打分**：对每个候选图像按维度给出 0–4 分的评估，最终偏好通过加权总分比较得出。

形式化表述如下：

\[
R = \{(d_i, w_i, L_i)\}_{i=1}^{N}, \quad
S(I_k) = \sum_{i=1}^{N} w_i \cdot s_i^k
\]

最终选择总分更高的图像作为偏好结果。

### 2.2 训练数据构建

- **分类驱动的平衡采样**：使用 DeepSeek-V3.2 对提示词/编辑指令进行多标签分类，覆盖文本到图像（6 个一级类/42 个二级类）与图像编辑（12 个一级类/30 个二级类），据此指导开放数据集的平衡采样及长尾类别补充合成。
- **数据来源**：文本到图像数据来自 HPD v3、OIP、EvalMuse-40K 及补充合成数据（共 31,835 对）；图像编辑数据基于 EditReward-Data（共 30,695 对）。
- **Rubric 轨迹合成**：使用 Gemini 3.1 Pro 作为教师模型，**以人类偏好标签为条件**合成完整训练轨迹（任务意图 → 维度与权重 → 分级标准 → 逐维度评分），而非让教师独立判断偏好。通过解析校验和偏好方向一致性检查进行质量控制。

### 2.3 两阶段训练流程

**阶段一：监督微调（SFT）**

模型以最大似然方式模仿教师合成的完整 rubric 轨迹，学习"意图分解 → 维度选择与加权 → 评分标准制定 → 逐维度评分 → 偏好决策"的完整评估范式：

\[
\mathcal{L}_{\text{SFT}} = -\sum_j \sum_{t=1}^{T_j} \log \pi_\theta(t_{j,t} | x_j, t_{j,<t})
\]

**阶段二：GRPO 强化学习（维度级奖励）**

- **固定 Rubric 采样**：训练时固定教师生成的 rubric 作为条件上下文，仅对被评估部分的维度评分进行采样，保证预测与参考维度一一对应、奖励可比；推理时仍端到端生成完整 rubric 与评分。
- **维度级奖励设计**：对每个维度计算预测分数差与参考分数差的差距，综合**方向因子**（方向一致=1.0，一方为平局=0.6，方向相反=0.1）与**幅度因子**：

\[
b_i = 1 - \frac{|\Delta_i^{\text{pred}} - \Delta_i^{\text{gt}}|}{2(s_{\max} - s_{\min})}, \quad
R = \sum_{i=1}^{N} w_i b_i \phi_i
\]

- **饱和分组过滤**：当同一输入采样的 G 个响应奖励标准差过小（σ < 0.05）时，将该组优势置零，避免低区分度组中的噪声被归一化放大为误导性策略更新。

## 6. 论文的主要结论与发现

1. **RubricRM-Gen-9B** 在文本到图像基准上取得最佳奖励模型成绩：MMRB2 72.00、GenAI-Bench 74.12、GenAI-Bench-Verified 84.45，超越最强基线 UnifiedReward-Flex-8B 分别约 2.80/0.72/0.25 分；
2. **RubricRM-Edit-9B** 在图像编辑基准上全面领先：MMRB2 75.40、EditReward-ERB Avg 46.40、EditScore-ERB Avg 85.64，且在 EditScore-ERB 的 Prompt Following、Consistency、Overall Quality 三个细粒度指标上均取得高分，表明动态 rubric 能有效平衡指令遵循、源一致性保持与视觉质量；
3. **两阶段训练各自分工明确**：SFT 贡献了绝大部分增益（文本到图像 3.4–13.1 分，图像编辑 6.5–13.1 分），确立了 rubric 评估范式；维度级 GRPO 提供一致但较小的额外提升（约 0.4–2.2 分），校准了评分精度；
4. **Label-only 对比实验**证明增益不仅来自数据本身，更来自 rubric 轨迹所教授的"先分解标准、再做判断"的评估范式；
5. **Rubric 具有稳定性和适应性**：同一指令重复采样时维度相似度高（Gen 0.763 / Edit 0.800）且权重差异小；相似性排序为同指令 > 同类型 > 不同类型，说明模型能根据指令类型调整评估标准；
6. **饱和分组过滤**有效防止了 GRPO 训练中奖励均值崩溃、响应长度飙升和熵塌缩等不稳定现象。

## 7. 优点

- **范式创新**：将"动态 rubric 生成 + 基于 rubric 的评分"整合进单一自包含的生成式奖励模型，填补了自由文本 rationale 与标量偏好之间的空白层，兼具可解释性与任务自适应性；
- **训练方法论细致**：两阶段训练设计清晰，SFT 学范式、GRPO 校准打分；维度级奖励明确区分方向错误、平局错配与幅度误差，梯度信号远比二元偏好密集；
- **数据工程扎实**：分类驱动的平衡采样、长尾类别补充合成、多标签分层抽样、教师轨迹质量控制（含偏好方向一致性校验）等环节考虑周全；
- **实验证据链完整**：从主实验到消融、从 rubric 质量分析到跨教师敏感性，多角度支持核心主张；
- **开源贡献**：模型、数据、代码全部公开，便于复现与后续研究。

## 8. 不足与局限

- **对专有教师模型的依赖**：rubric 轨迹由 Gemini 3.1 Pro 合成，教师模型的偏差（如维度偏好、评价粒度习惯）可能被学生模型继承；尽管跨教师分析显示一定鲁棒性，但无法完全消除；
- **评测任务范围有限**：仅覆盖静态图像的文本到图像生成与指令编辑，未涉及视频生成、时序编辑等更复杂场景，而这些场景中时间一致性需要额外的评分维度与机制；
- **未与部分同类方法直接比较**：未与 AutoRubric-T2I、Auto-Rubric as Reward 等采用"冻结 VLM+外部规则"路线的近期工作实证对比，削弱了对该领域内方法选择的参考价值；
- **算力信息不完整**：未披露训练总时长与具体效率，难以评估方法的训练成本；
- **主实验单次运行结果**：未报告多次运行的方差或置信区间，可能影响对小幅性能差异（如 0.25 分差距）的判断稳健性；
- **潜在主观偏差**：人类偏好标签和教师轨迹本身可能包含主观或系统性偏差，模型输出的 explicit rubric 应视为模型判断而非客观标准，在下游 RL 优化中此类偏差可能被放大。
