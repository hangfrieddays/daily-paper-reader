## 摘要
指令式图像编辑采用规划器-渲染器流水线：视觉语言模型（VLM）首先将指令转换为编辑计划，然后扩散模型执行该计划。仅使用最终图像奖励训练此类系统效率低下，因为一次糟糕的编辑无法揭示额外优化应更侧重于规划器还是渲染器，且即使在规划器主导的情况下，也难以在自由形式的推理轨迹中定位问题。我们提出DARS，一种针对这种两阶段设置的双层信用分配强化学习框架。在模块间，多计划多渲染 rollout 估计计划间和计划内奖励变异性以进行软模块路由，而 rollout 平均奖励提供自适应课程难度估计。在规划器内部，四字段结构化推理输出支持前缀门控奖励和令牌级优势重新加权，将结果级反馈转化为局部监督。在五个基准上的实验表明，DARS 在相同骨干网络、数据、奖励模型和 rollout 预算下优于联合强化学习基线，在推理密集型编辑上提升最大。

## Abstract
Instruction-based image editing uses a planner-renderer pipeline: a vision-language model (VLM) first converts the instruction into an edit plan, and a diffusion model then executes that plan. Training such systems with only final-image rewards is inefficient because a poor edit does not reveal whether additional optimization should place more emphasis on the planner or the renderer, and even planner-dominant cases remain difficult to localize within a free-form reasoning trace. We present DARS, a reinforcement learning framework for dual-level credit assignment in this two-stage setting. Across modules, multi-plan multi-render rollouts estimate between-plan and within-plan reward variability for soft module routing, while rollout mean rewards provide hardness estimates for an adaptive curriculum. Within the planner, a four-field structured reasoning output enables a prefix-gated reward and token-level advantage reweighting, turning outcome-level feedback into localized supervision. Experiments on five benchmarks show that DARS outperforms a Joint~RL baseline with the same backbone, data, reward model, and rollout budget, with the largest gains on reasoning-intensive edits.

# DARS：基于结构化推理的双层信用分配强化学习用于指令式图像编辑

## 1. 核心问题与整体含义

- **研究背景**：指令式图像编辑通常采用“规划器-渲染器”两阶段流水线——视觉语言模型（VLM）先将编辑指令转化为结构化的编辑计划，扩散模型再据此执行编辑。如何高效训练这一两阶段系统是当前挑战。
- **核心问题**：仅使用最终图像奖励进行训练时，一次失败的编辑无法判断错误来源：问题出在规划器（计划不合理）还是渲染器（执行不到位）？即使在规划器主导的错误中，也难以定位自由形式推理轨迹中的具体出错步骤。
- **整体含义**：传统联合强化学习（Joint RL）把系统视为整体优化，缺乏模块级信用分配与内部推理级信用分配，导致优化信号稀疏、训练效率低。DARS 正是为了解决这一“双层信用分配”问题而提出的强化学习框架。

## 2. 方法论

### 2.1 总体架构

DARS 在“双层级”上实现信用分配：

- **跨模块级（模块间）**：区分错误应归因于规划器还是渲染器。
- **模块内级（规划器内部）**：将结果级奖励转化为规划器推理轨迹的局部监督信号。

### 2.2 跨模块信用分配：多计划多渲染 rollout

- 对同一输入指令，采样 **多个编辑计划**，每个计划再对应 **多个渲染结果**，构成多计划多渲染 rollout。
- 利用两组统计量估计奖励变异性：
  - **计划间变异性**：不同计划下渲染结果奖励的差异程度。
  - **计划内变异性**：同一计划下多次渲染结果的奖励差异。
- **软模块路由**：根据变异性大小软性地将优化重点分配给规划器或渲染器——若计划间差异大，则问题更可能出在规划器；若计划内差异大，则问题更可能在渲染器。
- **自适应课程**：rollout 的平均奖励作为任务难度估计——平均奖励低的任务被赋予更高权重或更晚加入训练，形成由易到难的自动课程。

### 2.3 模块内信用分配：四字段结构化推理

- 规划器不再输出完全自由形式的推理，而是强制生成 **四个字段** 的结构化推理输出，将推理过程拆分为可定位的语义单元。
- **前缀门控奖励**：对结构化推理的不同前缀（前一个、前两个字段等）计算局部奖励贡献，将最终奖励反向分配到各推理前缀阶段。
- **Token 级优势重加权**：在强化学习策略更新时，根据每个 token 对完成推理目标的贡献程度重新加权其优势估计，使得规划器在推理轨迹上得到细粒度、可定位的梯度信号。

### 2.4 算法流程（文字描述）

1. 对批次中的指令生成多个编辑计划 → 对每个计划执行多个渲染。
2. 计算计划间/计划内奖励变异性 → 软路由决定优化模块权重。
3. 计算 rollout 平均奖励 → 更新课程难度。
4. 在规划器内部：基于四字段结构化推理，计算前缀门控奖励和 token 级优势重加权。
5. 综合所有信号进行策略梯度更新。
