## 摘要
高质量的电商创意对于展示产品和传达营销信息至关重要。最近的扩散模型实现了可扩展的创意生成，并产生视觉上引人注目的图像，但其扁平的栅格输出通常包含扭曲的文本和不一致的产品细节，需要在部署前进行优化。此外，由于缺乏显式结构，生成的创意难以编辑和复用，而复杂的设计需求仍难以编码为可验证的训练信号。为应对这些挑战，我们提出了CommerceVibe，它将创意表示为可执行的视觉代码，并将生成过程表述为条件化HTML/CSS程序合成。给定产品图像、设计需求和产品信息，它能生成可渲染、可编辑和可复用的创意。我们进一步引入了双反馈强化学习，其中基于规则的反馈评估渲染程序的可读性、产品可见性和布局有效性，而来自视觉语言模型（VLM）的视觉反馈则根据输入规范评估渲染创意的六个感知和商业维度。这些互补的反馈信号共同提升了约束满足和感知相关质量。我们在超过28,000个电商示例上对Qwen3.5-9B进行了监督微调（SFT），随后进行了双反馈强化学习。在包含1,300个案例的基准测试中，优化后的CommerceVibe模型获得了94.0/100的加权得分，而仅使用SFT的变体得分为87.3，并且优于强大的外部模型。五位电商设计专家的盲评进一步验证了这些改进。CommerceVibe支持可控、可编辑和可扩展的电商创意生产。

## Abstract
High-quality e-commerce creatives are essential for presenting products and conveying marketing messages. Recent diffusion models enable scalable creative generation and produce visually compelling images, but their flattened raster outputs often contain distorted text and inconsistent product details, requiring refinement before deployment. Moreover, without explicit structure, the resulting creatives are difficult to edit and reuse, while complex design requirements remain challenging to encode as verifiable training signals. To address these challenges, we present CommerceVibe, which represents creatives as executable visual code and formulates generation as conditional HTML/CSS program synthesis. Given product images, design requirements, and product information, it produces renderable, editable, and reusable creatives. We further introduce dual-feedback reinforcement learning, in which rule-based feedback evaluates rendered programs for text readability, product visibility, and layout validity, while visual feedback from a vision-language model (VLM) assesses rendered creatives against input specifications across six perceptual and commercial dimensions. Together, these complementary feedback signals improve both constraint satisfaction and perception-dependent quality. We perform supervised fine-tuning (SFT) of Qwen3.5-9B on over 28,000 e-commerce examples, followed by dual-feedback reinforcement learning. On a 1,300-case benchmark, the optimized CommerceVibe model achieves a weighted score of 94.0/100, compared with 87.3 for the SFT-only variant, and outperforms strong external models. Blind evaluations by five e-commerce design experts further validate these improvements. CommerceVibe supports controllable, editable, and scalable e-commerce creative production.

### 2. 方法论：核心思想、关键技术细节与算法流程

#### 核心思想

- 将生成问题定义为：给定产品图像 `I`、自由形式用户请求 `u`、可选产品信息 `m`，输出一个完整的 HTML/CSS 文档 `c`。
- 产品图像**直接以 URL 引用**而不是重新生成，文本用**原生 HTML 元素**呈现而非像素合成，从根本上避免文本扭曲和产品特征漂移。
- 生成结果可通过浏览器渲染，DOM、元素框、可见文本、图像引用等可以被自动检查，从而提供可验证的训练信号。

#### 技术细节

1. **请求归一化（Request Normalization）**
   - 固定预处理流程将自由文本请求转换为结构化格式 `ũ = Normalize(I, u, m)`，不引入额外产品事实，且在 SFT、RL、评估中保持一致。

2. **策略模型与生成**
   - 基于 Qwen3.5-9B 多模态模型，在固定系统指令下，单次解码生成一个完整 HTML/CSS 文档。
   - 模型参数化生成概率：
     \[
     \pi_\theta(c|x)=\prod_{t=1}^T \pi_\theta(y_t|x,y_{<t})
     \]

3. **两阶段训练**
   - **阶段一：监督微调（SFT）**：在 28,568 个质检后的真实电商示例上微调，最小化负对数似然：
     \[
     L_{\text{SFT}}(\theta)=-\mathbb{E}_{(r,c^*)\sim D_{\text{SFT}}}\left[\sum_{t=1}^{T^*}\log\pi_\theta(y_t^*|x,y_{<t}^*)\right]
     \]
   - **阶段二：双反馈强化学习（GRPO）**：从同一 SFT 策略出发，采样 K 个候选，渲染后计算两种奖励并归一化优势：
     \[
     \hat{A}_k=\frac{R_k-\text{mean}(R_{1:K})}{\text{std}(R_{1:K})+\epsilon}
     \]

4. **基于规则的反馈（Rule-Based Feedback）**
   - 分为三类错误：
     - **Text Readability**：文本溢出、重叠、覆盖产品、字号过小、对比度不足。
     - **Product Visibility**：产品图像是否缺失、裁剪、不突出、相互遮挡。
     - **Layout Validity**：元素是否越界、视觉中心是否平衡、底部留白是否合理。
   - 规则配置按输入产品图像数量区分：`Single`（1 张）强调主产品突出；`Multi`（≥2 张）要求所有产品出现并检测遮挡。
   - 渲染后才判定“可检测性”，不适用的维度从权重聚合中剔除并重新归一化。
   - 包含保护门：格式错误、空页、缺图、严重产品覆盖不足、文本稀疏惩罚；关键错误（文本溢出、重叠、越界、产品遮挡）有额外惩罚。
   - 规则奖励最终映射为：
     \[
     R_{\text{rule}}=\text{clip}\left(\frac{\tilde{S}_{\text{rule}}-40}{10},-1,1\right)
     \]

5. **VLM 偏好反馈（VLM Preference Feedback）**
   - 使用固定的 Qwen3-VL-Plus 作为 Judge，对渲染截图进行六维度 1–5 评分：
     - 视觉吸引力、产品呈现、感知可读性、营销相关性、商业可用性、文案保真度。
   - 各维度加权聚合，低分（≤2）有额外惩罚，映射为偏好奖励 \(R_{\text{pref}}\)。
   - Judge 接收截图、产品图、归一化请求、产品信息，但不接收规则分数，避免信息泄漏。
   - 组合奖励：
     \[
     R_{\text{comb}}=\frac{1}{2}R_{\text{rule}}+\frac{1}{2}R_{\text{pref}}
     \]

6. **优化目标**
   - 使用标准带裁剪的 GRPO 目标，并加入参考策略 KL 正则，防止偏离 SFT 策略过远。

### 3. 实验设计

#### 数据集与场景

- **SFT 语料**：28,568 训练样例 + 3,174 验证样例，来源为真实电商设计场景；其中 Single 23,726、Multi 4,842。
- **评测基准**：共 1,300 个案例，其中 Single 1,140（87.69%）、Multi 160（12.31%）；覆盖 34 个常见电商类目（家居、美妆、3C、食品、服饰、宠物等）。
- 基准与训练数据在产品级完全隔离，每个案例产品不重复。

#### 对比方法

- **CommerceVibe 变体**：
  - Qwen3.5-9B 基座策略
  - + SFT
  - + Rule-RLVR（仅规则反馈）
  - + Preference-RL（仅 VLM 偏好反馈）
  - + Rule+Preference RL（双反馈，即完整 CommerceVibe）
- **外部模型**：
  - GPT-5.5
  - Claude Opus 4.8
  - Gemini 3.5 Flash
- 所有方法在相同归一化输入、相同系统指令、单次生成（无迭代修正、无候选重排）条件下评估。

#### 评测指标

- 自动指标：`S_rule ∈ [0,50]`、`S_pref ∈ [0,50]`、`S_overall = S_rule + S_pref ∈ [0,100]`。
- 专家指标：5 位 1–5 年经验的电商设计专家进行盲评，输出 `S_expert ∈ [0,100]`；结果归一化后计算 ICC 一致性。
- 统计检验：Wilcoxon 符号秩检验、Holm 校正、Bootstrap 置信区间。

### 6. 主要结论与发现

- **主结果**：CommerceVibe（Rule+Preference RL）在 1,300 案例上达到 `S_overall = 94.0`，显著高于仅 SFT 的 87.3 和基座的 70.1；外部模型中 GPT-5.5 最佳（80.1），但明显低于 CommerceVibe。
- **专家评估**：CommerceVibe 专家评分 90.0，同样排名第一，且与自动结果方向一致。
- **双反馈互补性**：
  - Rule+Preference RL 相比最强单反馈变体（Rule-RLVR）在 Multi 上提升 +4.8 分，在 Single 上提升 +1.2 分，证明规则反馈与 VLM 偏好反馈互补，尤其在多产品场景。
- **规则族消融**：删除 Layout 规则导致 Layout 得分下降最大（−4.47），说明显式几何约束对整体质量最重要；Product 规则主要影响产品维度；删除 Product 规则还会轻微降低 Text 分数，说明产品区域占用会影响文字空间。
- **结构与可编辑性**：以 HTML/CSS 作为表示，成功避免了文本扭曲和产品特征漂移，同时支持元素级编辑和复用，验证了可执行视觉代码在电商创意生成中的潜力。

### 7. 优点

- **表示创新**：将创意图生成转化为 HTML/CSS 程序合成，天然支持渲染验证、元素编辑和复用，克服扩散模型“扁平栅格”的固有缺陷。
- **奖励设计巧妙**：
  - 规则反馈精确针对局部结构错误（文本、产品、布局），可解释、可审计。
  - VLM 偏好反馈捕捉整体感知与商业质量，两者互补。
- **条件化规则**：根据输入产品图像数量（Single/Multi）动态调整规则权重和检测器，适应不同任务复杂度。
- **训练细节扎实**：固定归一化流程、固定系统指令、单次生成设定、保护门机制、KL 正则，避免奖励黑客和发散。
- **评价系统完善**：自动 + 专家双轨评估，包含统计检验、置信区间、消融和训练动态诊断，可比性强。

### 8. 不足与局限

- **规则设计依赖人工**：
  - 规则阈值、权重、关键错误定义均为手工设定，未做自动搜索或灵敏度分析；不同 e-commerce 场景可能需要重新调整。
- **VLM Judge 独立性不足**：
  - 偏好评估器使用 Qwen3-VL-Plus，与策略同属一个技术栈，可能存在系统性偏好偏差；论文也未在 RL 中迭代更新 Judge，未来需要独立评估器验证泛化性。
- **Multi 场景覆盖有限**：
  - 基准中 Multi 仅 160 例，且最多 8 张输入图；对更复杂、更多产品的合成场景缺乏充分验证。
- **外部模型对比公平性**：
  - 外部模型被限制为“单次生成、无迭代修正”，而实际闭源 API 模型通常可通过多轮对话纠错；论文虽声称设定一致，但可能低估了外部模型的真实能力。
- **算力信息不完整**：
  - 未报告训练时长、推理成本、GPU 利用率等，难以评估部署成本。
- **自动化指标与专家判断仍有差距**：
  - 自动–专家相关度中等（ρ=0.612），说明当前规则 + VLM 评分仍不能完全模拟人类专业审美。
- **应用限制**：
  - 依赖 HTML/CSS 渲染环境；对于复杂位图特效（如光影、材质纹理）可能不如扩散模型表现力强，适用范围偏向结构化排版型创意。
