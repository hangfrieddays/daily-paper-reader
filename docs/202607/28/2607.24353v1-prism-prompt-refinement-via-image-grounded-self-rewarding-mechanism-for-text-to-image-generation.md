## 摘要
文本到图像生成模型可以从自然语言描述中合成高质量的图像，但其性能对提示词的编写高度敏感。现有的提示优化方法主要依赖文本侧重写、提示扩展或外部奖励信号，对基于图像的诊断有限，且难以学习可复用的优化策略。本文提出PRISM，一种基于图像自奖励机制的提示优化框架。PRISM通过结构化视觉诊断解释生成的图像，并从语义一致性、美学质量和人类偏好对齐方面对其进行评分，从而闭合提示-图像-反馈循环。它首先通过多任务监督微调初始化统一的视觉语言模型，然后通过结合理想点与切比雪夫奖励的自奖励优化改进提示策略。大量实验表明，PRISM提升了整体图像质量和细粒度语义对齐，同时为目标提示优化提供了可解释的反馈。代码可在 https://anonymous.4open.science/r/PRISM-FF81 获取。

## Abstract
Text-to-image generation models can synthesize high-quality images from natural language descriptions, but their performance remains highly sensitive to prompt formulation. Existing prompt optimization methods mainly rely on text-side rewriting, prompt expansion, or external reward signals, offering limited image-grounded diagnosis and weak support for learning reusable optimisation policies. In this paper, we propose PRISM, a Prompt Refinement framework via Image-grounded Self-rewarding Mechanism. PRISM closes the prompt-image-feedback loop by interpreting generated images with structured visual diagnosis and scoring them along semantic consistency, aesthetic quality, and human preference alignment. It first initializes a unified VLM through multi-task supervised fine-tuning, and then improves the prompt policy via self-rewarding optimization with a hybrid ideal-point and Chebyshev reward. Extensive experiments show that PRISM improves holistic image quality and fine-grained semantic alignment, while providing interpretable feedback for targeted prompt refinement. The code is available at https://anonymous.4open.science/r/PRISM-FF81.

## 2. 方法论：核心思想、关键技术细节
- **核心思想**：训练一个统一的视觉语言模型（VLM），同时具备提示重写和结构化视觉反馈评估能力；通过自奖励强化学习，利用图像诊断信号持续优化提示策略。
- **技术细节**：
  - **结构化视觉反馈构建**：从三个维度评估生成图像：语义一致性（对象/属性/关系等）、美学质量（构图/光照/色彩等）、人类偏好对齐（自然度/吸引力等）。每个维度输出文本诊断和1-10分评分。
  - **Stage I：多任务监督初始化**：构建四类训练数据：提示重写 \(D_{rew}\)、视觉反馈评估 \(D_{fb}\)、纯分数校正 \(D_{score}\)、反馈引导重写 \(D_{fgr}\)。使用响应自回归损失联合微调VLM。
  - **Stage II：自奖励策略优化**：
    1. 从当前策略采样K个候选提示，冻结T2I生成器产生图像。
    2. 用冻结的VLM以反馈评估模式输出三维分数向量 \(\mathbf{r} = [r_{sem}, r_{aes}, r_{pref}]\)。
    3. **混合奖励聚合**：
       - 归一化分数后计算加权偏差 \(\mathbf{d}_i = \mathbf{w} \odot (\mathbf{r}^* - \bar{\mathbf{r}}_i)\)。
       - 理想点奖励 \(R_i^{ideal} = 1 - \|\mathbf{d}_i\|_2 / \|\mathbf{w} \odot \mathbf{r}^*\|_2\)，切比雪夫奖励 \(R_i^{cheb} = 1 - \|\mathbf{d}_i\|_\infty / \|\mathbf{w} \odot \mathbf{r}^*\|_\infty\)。
       - 最终标量奖励 \(R_i = \alpha R_i^{ideal} + (1-\alpha)R_i^{cheb}\)，平衡整体提升与最弱维度惩罚。
    4. 组内优势估计，使用组序列策略优化（GSPO）更新策略，含KL正则化。
- **推理阶段**：给定原始提示，PRISM可输出优化后的提示和结构化视觉反馈，支持迭代精炼。

## 6. 主要结论与发现
- PRISM在整体图像质量和细粒度语义对齐上均显著优于所有基线，尤其在PickScore、HPSv2、ImageReward、TIFA和T2I-CompBench平均分上达到最优。

- 迭代精炼可进一步改善低分样本，表明PRISM不仅是单次增强器，还可作为反馈感知的迭代优化器。
- 结构化视觉诊断提供可解释的纠正线索，指导目标性提示修改。
