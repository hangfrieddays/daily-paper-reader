## 摘要
我们提出了AdvantageFlow，一种用于整流流模型的前向过程强化学习算法。与优化反向过程的Flow-GRPO不同，我们优化了一个优势加权的前向过程预测损失。当优势为负且损失变为非凸时，该优化问题不稳定。我们通过展开策略正则化来稳定它，这降低了方差，并源于拟合局部奖励改善目标分布。我们在使用Stable Diffusion 3.5 Medium的图像生成任务上评估了AdvantageFlow。它优于Flow-GRPO和一种基于负面感知微调的最先进的前向过程强化学习基线。

## Abstract
We introduce AdvantageFlow, a forward-process reinforcement learning algorithm for rectified flow models. Unlike Flow-GRPO, which optimizes the reverse process, we optimize an advantage-weighted forward-process prediction loss. This optimization problem is unstable when advantages are negative and the loss becomes non-convex. We stabilize it by rollout policy regularization, which reduces variance and arises from fitting a local reward-improving target distribution. We evaluate AdvantageFlow on image generation tasks with Stable Diffusion 3.5 Medium. It outperforms both Flow-GRPO and a state-of-the-art forward-process RL baseline based on negative-aware fine-tuning.

## 1. 核心问题与整体含义（研究动机与背景）

- **研究背景**：流模型（如扩散模型、整流流）是图像生成的主流模型，通常先通过流匹配损失预训练，再通过强化学习（RL）后训练以优化奖励（如人类偏好、文本对齐等）。现有 RL 方法多基于逆过程（即去噪采样轨迹），如 Flow-GRPO，但其需要引入随机随机性来生成策略梯度，且面临信用分配问题（最终奖励需归因到中间去噪步）。
- **核心问题**：是否存在一种更简单、稳定的 RL 方法，不依赖于逆过程的序列优化？前向过程 RL（forward-process RL）可避免这些问题：直接采样完整图像、评分、然后用前向预测损失加权训练。但直接使用优势（advantage）加权时，负优势会导致非凸损失，优化不稳定。
- **研究目标**：提出 AdvantageFlow，一种前向过程 RL 算法，通过优势加权最小二乘并引入推出策略正则化（rollout regularization）来稳定训练，同时减少梯度方差。

## 2. 方法论：核心思想、关键技术细节

- **核心思想**：
  - 基于优势（reward 减去批量平均）对前向预测损失进行加权：正优势放大“好”样本，负优势抑制“坏”样本。
  - 为克服非凸性，引入 **推出策略正则化**（rollout regularization）：强制当前策略的预测向推出策略（旧策略）的预测靠拢，保证每个样本的二次系数严格为正，从而保持损失严格凸。
  - 同时引入 **参考策略正则化**（reference regularization），防止模型丢失未被奖励覆盖的能力（如多样性、质量）。

- **关键技术细节**：
  - **优势计算**：对每批图像标准化优势：\( A_{i,k} = \text{clip}\left( \frac{r_{i,k} - \bar{r}_i}{Z}, -1, 1 \right) \)，其中 \(\bar{r}_i\) 为每个 prompt 的均值，\(Z\) 为全批标准差。
  - **损失函数**（公式5）：
    \[
    \ell = A \|f_\theta - x_0\|^2 + \gamma \|f_\theta - f_{\text{old}}\|^2 + \lambda \|f_\theta - f_{\text{ref}}\|^2
    \]
    其中 \(f_\theta\) 为当前模型预测的干净图像，\(f_{\text{old}}\) 为推出策略预测，\(f_{\text{ref}}\) 为初始预训练模型预测。
  - **变体**：AdvantageFlow(1.1) 固定 \(\gamma=1.1\)；AdvantageFlow(1−A) 自适应 \(\gamma=1-A\)，使得总二次系数恒为 \(1+\lambda\)，等同于 DiffusionNFT 的特例（当 \(\beta=1\)）。
  - **算法流程**（Algorithm 1）：
    1. 初始化：\(\theta = \theta_{\text{ref}}\)，\(\theta_{\text{old}} = \theta_{\text{ref}}\)
    2. 每轮：采样 L 个 prompts，每个 prompt 用推出策略生成 K 张图像（用 ODE 采样）
    3. 计算每张图像的优势
    4. 采样随机时间 t 和噪声 ϵ，构建带噪图像 \(x_t\)
    5. 最小化上述损失（梯度下降）
    6. 用指数移动平均（EMA）更新推出策略：\(\theta_{\text{old}} = \rho \theta_{\text{old}} + (1-\rho)\theta\)
