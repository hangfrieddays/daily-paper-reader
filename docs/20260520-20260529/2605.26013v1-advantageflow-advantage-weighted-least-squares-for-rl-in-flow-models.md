## 摘要
我们提出了AdvantageFlow，一种用于整流流模型的前向过程强化学习算法。与优化反向过程的Flow-GRPO不同，我们优化了一个优势加权的前向过程预测损失。当优势为负且损失变为非凸时，该优化问题不稳定。我们通过推出策略正则化来稳定它，这降低了方差，并源于拟合一个局部奖励改进的目标分布。我们在Stable Diffusion 3.5 Medium上对AdvantageFlow进行了图像生成任务的评估。它优于Flow-GRPO和基于负感知微调的最先进的前向过程强化学习基线。

## Abstract
We introduce AdvantageFlow, a forward-process reinforcement learning algorithm for rectified flow models. Unlike Flow-GRPO, which optimizes the reverse process, we optimize an advantage-weighted forward-process prediction loss. This optimization problem is unstable when advantages are negative and the loss becomes non-convex. We stabilize it by rollout policy regularization, which reduces variance and arises from fitting a local reward-improving target distribution. We evaluate AdvantageFlow on image generation tasks with Stable Diffusion 3.5 Medium. It outperforms both Flow-GRPO and a state-of-the-art forward-process RL baseline based on negative-aware fine-tuning.

## 1. 论文的核心问题与整体含义（研究动机和背景）
- **背景**：流模型和扩散模型是图像生成的主流框架。预训练后常需通过强化学习（RL）进行后训练以对齐人类偏好、提升提示遵循能力。现有RL方法多基于逆向过程（如Flow-GRPO），将去噪视为序列决策，需引入随机性计算策略梯度，且面临奖励归因问题（最终图像奖励需分配至中间步）。
- **核心问题**：前向过程RL（直接对完整生成图像评分，用奖励权重训练预测损失）更简单、无需归因，但存在关键不稳定因素——当优势为负时，优势加权损失变为非凸，可能导致优化发散。
- **整体含义**：提出**AdvantageFlow**，通过优势加权最小二乘损失结合**rollout策略正则化**，稳定非凸优化，同时保持前向过程RL的优势。在Stable Diffusion 3.5 Medium上超越Flow-GRPO和现有最先进前向过程方法（DiffusionNFT）。

## 2. 论文提出的方法论
### 核心思想
- 对每批生成图像计算**优势**（奖励减批次均值），用优势加权预测损失**鼓励高优势样本、抑制低优势样本**。
- 引入**rollout正则化**（对当前策略与缓慢更新的rollout策略的预测差异惩罚）确保损失每样本严格凸（当γ > 1时，即使负优势也能保持正二次系数）。
- 加入**参考正则化**（对与初始预训练模型的预测差异惩罚）防止能力遗忘。

### 关键技术细节
- **优势计算**：每prompt内标准化，再除以批量标准差，并对截断至[-1,1]。
- **损失函数**（以预测形式）：
  ```
  ℓ = A(x0,c) * ||fθ(xt,t,c) - x0||² 
      + γ * ||fθ(xt,t,c) - fold(xt,t,c)||² 
      + λ * ||fθ(xt,t,c) - fref(xt,t,c)||²
  ```
  - 第一项：优势加权预测损失
  - 第二项：rollout正则化（γ ≥ 0）
  - 第三项：参考正则化（λ ≥ 0）
- **凸性保证**：当A+γ+λ > 0时损失严格凸。由于A被截断至[-1,1]，取γ>1即可（如γ=1.1）。论文提出两种变体：
  - **AdvantageFlow (1.1)**：固定γ=1.1
  - **AdvantageFlow (1−A)**：γ=1−A，使总系数恒为1+λ（自适应正则化）
- **rollout策略更新**：指数移动平均（EMA）更新θold = ρθold + (1−ρ)θ。
- **算法流程**（伪代码简化）：
  1. 采样L个prompt，每个用rollout策略生成K张图像
  2. 计算每图像优势
  3. 对每张图像随机采样时间t和噪声ε，构建插值xt
  4. 利用最小化经验损失更新θ
  5. 更新rollout参数

- **GenEval提升**：与基础模型相比，AdvantageFlow显著改善对象、计数、颜色、位置等能力，且无cfg时即可超过带cfg的基模。
- **正则化强度重要性**：γ过大或过小均导致性能下降，最佳值接近1。
- **与DiffusionNFT的联系**：后者的损失可视为AdvantageFlow的一个特例（β=1时γ=1−A）。
