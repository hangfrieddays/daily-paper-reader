## 摘要
直接偏好优化（DPO）在大语言模型的对齐中取得了成功，但在文本到图像生成任务中仍面临挑战。现有研究局限于去噪扩散模型，忽略了流匹配，并且在将基于离散NLP的DPO应用于基于回归的生成任务时存在目标不匹配问题。本文通过统一的逆向时间SDE框架，推导出覆盖扩散和流匹配的广义DPO目标，并从梯度角度指出标准DPO目标在文本到图像生成中是次优的。因此，我们提出了线性DPO，它用持续的线性效用函数替代了激进的基于Sigmoid的效用函数，并引入了EMA更新的参考模型。在扩散模型（SD1.5、SDXL）和流匹配模型（SD3-Medium）上的定性和定量实验表明，我们的方法优于现有基线。

## Abstract
Direct Preference Optimization (DPO) is successful for alignment in LLMs but still faces challenges in text-to-image generation. Existing studies are confined to denoising diffusion models while overlooking flow-matching, and suffer from an objective mismatch when applying discrete NLP-based DPO to regression-based generative tasks.\ In this paper, we derive a generalized DPO objective that covers both diffusion and flow-matching via a unified reverse-time SDE framework, and point out from a gradient perspective that the standard DPO objective is suboptimal for text-to-image generation. Consequently, we propose Linear-DPO, which replaces the aggressive sigmoid-based utility function with a sustained linear utility and incorporates an EMA-updated reference model. Qualitative and quantitative experiments on diffusion models (SD1.5, SDXL) and flow-matching model (SD3-Medium) demonstrate the superiority of our approach over existing baselines.

- **核心问题**：现有DPO方法存在两大限制：
  - **(a) 局限于扩散模型**：理论分析和验证仅在U-Net扩散模型（SD1.5、SDXL）上，无法适用于转向流匹配和MMDiT架构的最新模型（如SD3-Medium）。

- **论文目标**：设计统一的、适用于扩散和流匹配的DPO目标，并从根本上适配回归式训练需求。

## 2. 论文提出的方法论：核心思想、关键技术细节、算法流程
### 核心思想
- **统一框架**：通过逆向时间SDE将流匹配也纳入DPO框架。将流匹配的确定性ODE等价转化为一个速度场驱动的SDE，从而获得可处理的单步高斯条件分布，使DPO推导成立。
- **梯度分析揭示问题**：标准DPO的梯度可视为加权SFT（对获胜样本梯度下降，对落选样本梯度上升），权重为sigmoid函数 `ω = β̄ σ(β̄ ΔDθ)`。这导致：
  - 大规模`β̄`（T=1000时可达2500）远超NLP范围，造成剧烈梯度和训练不稳定。
  - 温度与更新幅度耦合，超参调优困难。
  - Sigmoid早期硬饱和，不适合长期稳定更新。
- **Linear-DPO 改进**：
  1. **替换sigmoid为线性效用函数**：`ω' = σ(β̄ ΔDθ)`（去掉外部β̄） → 改用 `u_linear(x) = 0.2x + 0.5`，并裁剪至`[η, 1]`（η=1e-2）。梯度更平滑持续。
  2. **EMA参考模型**：替代固定的参考模型，保持平滑更新而不突然切换。

### 关键技术细节
- **统一DPO目标推导**：通过SDE离散化，得到通用损失形式（公式11）：
  ```
  L(θ) = -E[ log σ( -β̄ λ(t) [ (||y_w - y_θ||² - ||y_w - y_ref||²) - (||y_l - y_θ||² - ||y_l - y_ref||²) ] ) ]
  ```
- **Linear-DPO 损失**（公式16）：
  ```
  L_Linear-DPO(θ) = E[ sg(ω'(ΔDθ)) * (||y_w - y_θ||² - ||y_l - y_θ||²) ]
  ```
  其中 `sg` 为停止梯度，实现加权SFT。
- **算法流程**（Algorithm 1）：
  1. 初始化策略 `θ` 和参考 `θ_ref` 相同。
  2. 采样偏好对 `(x_w, x_l, c)`、时间步 `t`、加噪样本。
  3. 计算策略和参考的预测。
  4. 计算Linear-DPO损失。
  5. 梯度更新策略。
  6. 用EMA更新参考：`θ_ref ← γ θ_ref + (1-γ) θ`（γ=0.995取得最佳）。
