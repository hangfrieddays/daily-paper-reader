## 摘要
在线强化学习日益成为将扩散模型与不可微目标对齐的重要工具。然而，现有方法在沿去噪轨迹分配细粒度信用以及实现稳定的基于值的优化方面仍面临限制。我们提出了一种用于扩散后训练的状态对齐潜在演员-评论家框架，其中扩散模型充当其自身的时间步条件值函数，并直接在含噪潜在状态上预测值。这支持轨迹级PPO训练，通过简单的条件设置和值预训练策略实现稳定的演员-评论家优化，并自然允许将学到的评论家重用于推理时引导。我们进一步将该框架扩展到多奖励优化，其中与互补奖励的联合训练有助于缓解奖励黑客攻击。在基于UNet和DiT的骨干网络上，我们的方法在单奖励和多奖励基准测试中持续优于先前的组相对RL和演员-评论家基线，同时测试时引导为生成质量提供了额外提升。

## Abstract
Online reinforcement learning is becoming increasingly important for aligning diffusion models with non-differentiable objectives. However, existing methods still face limitations in assigning fine-grained credit along denoising trajectories and in realizing stable value-based optimization. We propose a state-aligned latent actor-critic framework for diffusion post-training, in which the diffusion model serves as its own timestep-conditioned value function and predicts values directly on noisy latent states. This enables trajectory-level PPO training, supports stable actor-critic optimization with simple conditioning and value pretraining strategies, and naturally allows the learned critic to be reused for inference-time steering. We further extend the framework to multi-reward optimization, where joint training with complementary rewards helps alleviate reward hacking. Across both UNet- and DiT-based backbones, our method consistently outperforms prior group-relative RL and actor-critic baselines on single-reward and multi-reward benchmarks, while test-time steering provides additional gains in generation quality.

## 1. 核心问题与整体含义（研究动机和背景）

- **研究动机**：扩散模型通过大规模预训练已能生成高质量图像，但在用户关心的属性（如提示忠实度、组合正确性、美学、人类偏好）上仍不理想。后训练阶段使用强化学习（RL）优化不可微目标是一种有前景的途径，但面临两个关键挑战：
  - **信用分配**：奖励仅在最终图像上定义，而扩散生成涉及多步去噪轨迹，需要将最终奖励分配给中间状态和决策。
  - **稳定优化**：显式的演员-评论家方法易不稳定，现有批评家通常定义在像素空间（评估重建的干净图像代理），而非实际访问的噪声潜状态，导致批评家与策略不对齐、价值估计脆弱、解码开销大。
- **整体含义**：本文旨在设计一种稳定、高效且可扩展的演员-评论家框架，解决扩散模型后训练中的信用分配和优化稳定性问题，并支持多奖励优化和推理时导向。

## 2. 方法论：核心思想、关键技术细节与算法流程

### 核心思想
将预训练的扩散模型本身转换为时间步条件值函数（批评家），直接在噪声潜状态上预测价值，使批评家与策略共享相同状态空间和特征，实现状态对齐的信用分配。同时，引入简单但有效的训练稳定技术：时间步感知条件设置和价值预训练。进一步扩展到多奖励优化，通过共享骨干加独立价值头来缓解奖励破解。

### 关键技术细节

1. **状态对齐的潜在批评家**：
   - 将扩散模型（UNet或DiT）的骨干网络作为共享特征提取器，在其顶部添加轻量级注意力头和MLP，输出标量值V_φ(z_t, t, y)。
   - 对于UNet：将特征图patch化，附加可学习摘要令牌，通过注意力头和MLP预测值。
   - 对于DiT：在中间层（第7、15、23层）插入批评家分支，每个分支使用可学习查询令牌聚合图像令牌信息，产生批评家令牌，再拼接并通过MLP映射为标量。

2. **稳定批评家训练**：
   - **时间步条件**：在价值头的MLP中使用AdaLN风格的时间步调制，使头直接访问噪声水平，改善跨轨迹的价值预测。
   - **价值预训练**：在联合演员-评论家优化之前，进行短期的批评家预热阶段，仅从当前策略采样轨迹并优化批评家回归损失（蒙特卡洛回报），提升价值估计质量。

3. **推理时导向**：
   - 学到的批评家可直接在推理时使用：计算梯度∇_{z_t} V_φ，并将该方向注入采样器更新（DDIM或整流流），产生导向噪声预测或速度预测，使轨迹偏向高价值区域。

4. **多奖励优化**：
   - 使用共享骨干和每个奖励的独立轻量级价值头，避免不同奖励尺度冲突。通过联合训练互补奖励（如GenEval + HPS）缓解奖励破解，催生更丰富的场景和更好的美学。

### 算法流程（文字说明）
1. 初始化：从预训练扩散模型初始化策略π_θ；将扩散模型转换为批评家V_φ（添加轻量头）。
2. 价值预训练阶段：使用当前策略采样轨迹，仅更新批评家参数，最小化MSE损失。
3. 联合PPO训练：每迭代采样一批提示，生成图像，获得终端奖励。使用批评家计算优势（GAE，γ=1, λ=1及全局优势归一化）。通过裁剪的PPO目标更新策略，同时更新批评家。
4. 推理时导向：可选地，在采样过程中添加批评家梯度方向，增强生成质量。
